Open Windows 11 Admin Tools via Run

Windows 11 includes a comprehensive suite of administrative utilities used for troubleshooting, monitoring performance, and configuring system settings. This guide provides a quick and direct list of Run dialog commands that allow you to open the primary Windows Tools folder as well as launch specific administrative tools instantly without navigating through the graphical user interface.

How to Access the Run Dialog

To execute any of the commands listed below:

  1. Press the Windows Key + R on your keyboard to open the Run dialog box.
  2. Type the desired command into the Open: field.
  3. Press Enter or click OK.

Command to Open the Main Administrative Tools Folder

In Windows 11, Administrative Tools are consolidated under the name Windows Tools. You can open the entire folder containing shortcuts to all administrative utilities using either of these commands:

  • control admintools
  • tools

Run Commands for Individual Administrative Tools

If you need to access a specific utility directly, use its corresponding command in the Run box:

Tool Name Run Command Description
Computer Management compmgmt.msc Accesses storage, event logs, local users, and device settings in one console.
Event Viewer eventvwr.msc Displays detailed logs of system, security, and application events.
Performance Monitor perfmon.msc Monitors system performance metrics and hardware utilization in real time.
Resource Monitor resmon Displays detailed CPU, Memory, Disk, and Network usage.
Services services.msc Manages background services and their startup configurations.
Task Manager taskmgr Monitors running applications, background processes, and startup items.
Disk Management diskmgmt.msc Manages hard drives, partitions, drive letters, and file systems.
Device Manager devmgmt.msc Configures and updates drivers for hardware components.
System Configuration msconfig Configures system startup settings, boot options, and services.
Registry Editor regedit Modifies the Windows system registry settings.
Local Group Policy Editor gpedit.msc Configures user and computer policies (Windows 11 Pro/Enterprise only).
Local Security Policy secpol.msc Manages local computer security settings and user rights.
Windows Memory Diagnostic mdsched.exe Schedules a system reboot to test RAM for hardware errors.
Component Services dcomcnfg Configures COM+ applications and distributed transaction coordinator settings.
Disk Cleanup cleanmgr Scans and removes temporary and unnecessary system files.
System Information msinfo32 Displays comprehensive hardware resources, components, and software environment details.
