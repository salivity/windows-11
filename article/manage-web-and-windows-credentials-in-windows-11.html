Manage Web and Windows Credentials in Windows 11

Credential Manager in Windows 11 is a built-in vault that securely stores your saved usernames and passwords for websites, mapped network drives, Remote Desktop connections, and applications. This guide explains how to access Credential Manager, view stored details, and add, edit, or delete both Web Credentials and Windows Credentials to keep your saved authentication data up to date.

How to Open Credential Manager in Windows 11

  1. Press the Windows Key or click the Start button.
  2. Type Credential Manager in the search bar.
  3. Select Credential Manager from the search results to open the tool. (Alternatively, open Control Panel, set the view to "Large icons" or "Small icons," and select Credential Manager).

Once opened, you will see two primary tabs: Web Credentials and Windows Credentials.

Managing Web Credentials

Web Credentials store logins saved primarily by Microsoft Edge and specific Windows services.

To View Stored Passwords:

  1. Select the Web Credentials tab.
  2. Click the drop-down arrow next to the website or service you want to inspect.
  3. Click the Show link next to the hidden password.
  4. Enter your Windows 11 PIN, password, or biometric authentication to reveal the password.

To Remove a Web Credential:

  1. Expand the credential entry by clicking its arrow.
  2. Click Remove.
  3. Confirm the deletion when prompted.

Managing Windows Credentials (Windows Vault)

Windows Credentials store login details for local network shares, printers, Remote Desktop Protocol (RDP) sessions, and generic application credentials.

To Add a New Windows Credential:

  1. Select the Windows Credentials tab.
  2. Click Add a Windows credential (or Add a generic credential depending on your need).
  3. Enter the network address, server name, or IP (e.g., \\ServerName or 192.168.1.50).
  4. Enter the associated User name and Password.
  5. Click OK to save.

To Edit or Remove an Existing Windows Credential:

  1. Under Windows Credentials or Generic Credentials, find the entry you want to modify.
  2. Click the drop-down arrow to expand the details.
  3. Choose one of the following actions:
    • Edit: Update the username or password, then click Save.
    • Remove: Delete the stored credential completely, then click Yes to confirm.

Backing Up and Restoring Credentials

Windows 11 allows you to create a secure backup file of your Windows Vault entries:

  • To Back Up: In the Windows Credentials tab, click Back up Credentials, select a storage location, and set a password to protect the backup file (.crd).
  • To Restore: Click Restore Credentials, browse to your saved .crd file, enter the backup password, and follow the on-screen prompts to restore your credentials.
