Customize Quick Access and Home in Windows 11

This guide covers how to personalize the Home and Quick Access sections in Windows 11 File Explorer. You will learn how to pin or unpin folders and files, hide recent and frequent items, clear your activity history, and choose the default folder that opens when you launch File Explorer.

Change the Default Startup Location

You can set File Explorer to open directly to Home, This PC, or your cloud storage.

  1. Open File Explorer (press Win + E).
  2. Click the three dots (...) menu on the top toolbar and select Options.
  3. In the General tab, find the dropdown menu next to Open File Explorer to:.
  4. Select Home, This PC, or your personal OneDrive.
  5. Click Apply and then OK.

Pin and Unpin Folders in Quick Access

Quick Access allows you to keep frequently used folders at the top of the left navigation pane.

  • To pin a folder: Right-click any folder and select Pin to Quick access.
  • To unpin a folder: In the left sidebar or the Quick Access area, right-click the pinned folder and select Unpin from Quick access.
  • To reorder folders: Click and drag any pinned folder up or down within the Quick Access list to rearrange it.

Pin and Remove Files in Favorites

Windows 11 includes a Favorites section directly on the Home page for individual files.

  • To add a file to Favorites: Right-click the file and select Add to Favorites.
  • To remove a file from Favorites: Navigate to the Home page, right-click the file under the Favorites section, and select Remove from Favorites.

Show or Hide Recent Files and Frequent Folders

If you prefer a cleaner interface or want to improve privacy, you can disable automatic tracking of recent items.

  1. In File Explorer, click the three dots (...) and choose Options.
  2. Under the Privacy section in the General tab, check or uncheck the following options:
    • Show recently used files
    • Show frequently used folders
    • Show files from Office.com (if available)
  3. Click the Clear button next to Clear File Explorer history to instantly erase your past activity log.
  4. Click Apply and OK to save your changes.
