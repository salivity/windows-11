Use Storage Sense to Clear Cache in Windows 11

Managing temporary files and download caches in Windows 11 is essential for freeing up drive space and maintaining peak system performance. This guide explains how to enable, configure, and run Storage Sense to automate the deletion of unnecessary system caches, old downloads, and temporary application files, as well as how to perform manual cleanups.

How to Enable Storage Sense in Windows 11

Storage Sense is a built-in maintenance tool that automatically cleans up drives by removing unneeded items.

  1. Press Windows Key + I to open the Settings app.
  2. Select System from the left sidebar, then click on Storage on the right pane.
  3. Locate the Storage Management section.
  4. Toggle the switch next to Storage Sense to the On position.

Configuring Storage Sense for Temporary Files and Downloads

To ensure Storage Sense targets temporary system caches and the Downloads folder according to your preferences, adjust its automated cleanup schedule:

  1. In the Storage menu, click the arrow next to the Storage Sense toggle to open its configuration page.
  2. Check the box labeled Keep Windows running smoothly by automatically cleaning up temporary system and app files.
  3. Toggle Automatic User content cleanup to On.
  4. Set the Run Storage Sense dropdown to your preferred frequency: Every day, Every week, Every month, or During low free disk space.
  5. Under the Delete files in my Downloads folder... dropdown, choose a timeframe (1 day, 14 days, 30 days, 60 days, or Never) to automatically purge unneeded downloaded installers and cache files.
  6. Under the Delete files in my recycle bin... dropdown, choose your preferred retention period.

Running an Immediate Cleanup

If you need to free up storage space immediately without waiting for the automated schedule:

  1. Scroll to the bottom of the Storage Sense configuration page.
  2. Click the Run Storage Sense now button.
  3. Windows will scan your drive and delete temporary files, old download files, and cached items based on your configured rules.

Manually Removing Temporary System Caches

For deeper, granular control over specific temporary caches:

  1. Go back to Settings > System > Storage.
  2. Click on Temporary files in the storage breakdown list.
  3. Wait for Windows to scan the drive.
  4. Review and check the boxes for the file categories you want to delete, such as:
    • Delivery Optimization Files
    • Thumbnails
    • Windows Update Cleanup
    • Temporary Internet Files
    • DirectX Shader Cache
  5. Click Remove files at the top of the list to permanently delete the selected data.
