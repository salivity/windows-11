Assign Audio Devices to Specific Apps in Windows 11

Windows 11 allows you to route audio for individual applications to different input and output devices, making it easy to separate game audio, music, and voice calls. This guide provides step-by-step instructions on using the built-in Windows 11 Volume Mixer to customize sound playback and recording devices on a per-app basis.

Step 1: Open the Target Application

Before adjusting audio routing, open the application you want to customize and start playing audio (or make a sound). Windows 11 will only display active apps in the advanced sound mixer.

Step 2: Open Sound Settings

  1. Right-click the Speaker icon in the system tray on the bottom-right corner of your taskbar.
  2. Select Sound settings from the context menu (or press Windows Key + I, navigate to System, and click Sound).

Step 3: Access the Volume Mixer

  1. Scroll down to the Advanced section.
  2. Click on Volume mixer.

Step 4: Configure App-Specific Audio Devices

  1. Under the Apps section, locate the application you want to modify.
  2. Click the downward arrow next to the app's name to expand its settings.
  3. Use the Output device dropdown menu to select the specific playback device (such as headphones or external speakers) for that app.
  4. Use the Input device dropdown menu to choose the specific microphone or recording device for that app.

Your changes will take effect immediately. Windows 11 will remember these preferences each time the application is launched.

How to Reset Audio Preferences

If you ever need to restore all application audio settings to the system defaults:

  1. Return to the Volume mixer menu.
  2. Scroll to the bottom of the page.
  3. Click the Reset button next to Reset sound devices and volumes for all apps to the recommended defaults.
