How to Enable Dynamic Refresh Rate in Windows 11

Dynamic Refresh Rate (DRR) in Windows 11 automatically adjusts your laptop screen between a lower refresh rate for everyday tasks and a higher refresh rate for inking, scrolling, or gaming. This feature provides a smooth visual experience while conserving battery life. This guide covers the system requirements and the exact steps to enable and configure Dynamic Refresh Rate on compatible Windows 11 laptop displays.

System Requirements for Dynamic Refresh Rate

Before configuring DRR, ensure your laptop meets the following hardware and software specifications:

  • Operating System: Windows 11 (version 21H2 or later).
  • Display: A laptop panel that supports Variable Refresh Rate (VRR) and a native refresh rate of at least 120 Hz.
  • Graphics Driver: A graphics driver that supports Windows Display Driver Model (WDDM) 3.0 or higher.

Steps to Enable Dynamic Refresh Rate in Windows 11

  1. Open the Settings app by pressing Windows + I on your keyboard.
  2. In the left sidebar, select System, then click on Display on the right panel.
  3. Scroll down to the Related settings section and select Advanced display.
  4. If you have multiple monitors connected, ensure your laptop's internal display is selected in the dropdown menu at the top under Select a display to view or change its settings.
  5. Locate the Choose a refresh rate dropdown menu near the bottom of the page.
  6. Click the dropdown menu and select the option labeled Dynamic (for example, Dynamic (60 Hz or 120 Hz)).

Once selected, Windows 11 will automatically switch to the lower refresh rate during static tasks like reading or typing, and increase to the higher refresh rate during motion-heavy actions such as scrolling, gaming, or using a digital pen.

What to Do If the Dynamic Option Is Missing

If you do not see the "Dynamic" option in the refresh rate dropdown:

  • Update Graphics Drivers: Visit your laptop manufacturer’s website or your GPU vendor's control software (Intel, AMD, or NVIDIA) to install the latest display drivers.
  • Check Windows Updates: Go to Settings > Windows Update and install any pending updates.
  • Verify Panel Compatibility: Confirm with your laptop's technical specifications that the built-in screen natively supports dynamic or variable refresh rates at 120 Hz or above.
