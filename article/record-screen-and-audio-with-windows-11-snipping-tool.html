Record Screen and Audio with Windows 11 Snipping Tool

The Windows 11 Snipping Tool allows users to capture both video and internal system audio natively without requiring third-party software. This article explains how the tool captures system sound, the underlying mechanisms that enable audio recording, and how to configure audio inputs properly for screen captures.

The Audio Capture Mechanism

The Snipping Tool captures system audio by tapping directly into the Windows Core Audio APIs, specifically using Windows Audio Session API (WASAPI) in loopback mode. When you record system audio, the tool does not record the physical speakers through a microphone. Instead, it captures the digital audio stream that is being sent to your default playback device (such as headphones or speakers) right before it is rendered to the hardware. This ensures that the recorded audio is clean, free of room echo, and captured at its native digital quality.

Selecting Audio Sources

Before initiating a screen capture, the Snipping Tool interface provides dedicated toggles for audio configuration:

  1. System Audio: Clicking the speaker icon toggles the capture of internal sounds generated by apps, games, media players, or web browsers.
  2. Microphone Audio: Clicking the microphone icon enables external voice recording via your connected input device.

Both sources can be enabled simultaneously. When both are active, the Snipping Tool multiplexes (mixes) the microphone feed and the system loopback feed into a single stereo audio track within the resulting MP4 video file.

Step-by-Step Recording Process

  1. Open the Snipping Tool and select the Record (video camera) icon.
  2. Click New and drag the crosshairs to define the capture area on your screen.
  3. On the top toolbar, ensure the Speaker icon (System Audio) is unmuted.
  4. Click Start to begin the recording after the 3-second countdown.
  5. Click Stop when finished to preview, edit, or save the MP4 video with embedded audio.

Requirements and Troubleshooting

For the Snipping Tool to record audio successfully, several system settings must align:

  • Default Device: Loopback capture listens exclusively to the system's default output device. If an application outputs sound through a non-default device, that sound will not be recorded.
  • App Permissions: Windows requires microphone access permissions to be enabled in Settings > Privacy & security > Microphone if you plan to record voice commentary alongside system sound.
  • App Version: Audio recording requires Snipping Tool version 11.2307.44.0 or newer.
