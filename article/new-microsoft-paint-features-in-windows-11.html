New Microsoft Paint Features in Windows 11

The redesigned Microsoft Paint in Windows 11 transforms the classic lightweight graphics editor into a capable modern tool. This update introduces a completely refreshed user interface with dark mode, native support for layers and transparency, advanced AI-driven creative tools such as automated background removal and text-to-image generation, and improved canvas controls designed to streamline everyday digital artwork and photo editing.

Modern User Interface and Dark Mode

Microsoft Paint now aligns with the modern Windows 11 design language, featuring rounded corners, updated icons, and simplified toolbars. The interface automatically adapts to system themes, bringing full native dark mode support alongside light mode. The color palette, brush menus, and size pickers have also been simplified into streamlined dropdown menus for faster access.

Support for Layers and Transparency

For the first time in the app's history, Paint includes full layer management:

  • Multiple Layers: Users can add, reorder, duplicate, hide, and merge separate layers on the canvas, allowing for non-destructive image composition.
  • Alpha Channel & Transparency: Paint natively supports transparent backgrounds and true transparency in PNG files, eliminating the legacy limitation of default white canvas fills.

One-Click Background Removal

Using on-device machine learning, Paint can automatically detect the primary subject in an image and remove the background with a single click. Users can isolate people, products, or objects instantly without needing manual lasso selection tools.

Cocreator and Generative AI Tools

Paint integrates generative artificial intelligence directly into the editing workspace:

  • Cocreator: Powered by DALL-E, this feature generates high-quality artwork directly on the canvas based on user-provided text descriptions and chosen art styles.
  • Generative Erase: Enables users to brush over unwanted objects or blemishes, which the AI automatically removes while seamlessly filling the background.
  • Generative Fill: Allows users to select an area, enter a prompt, and seamlessly insert newly generated elements that match the lighting and style of the surrounding image.

Enhanced Zoom and Canvas Management

Canvas management has been overhauled to provide greater precision and control:

  • Centered Canvas: The drawing surface is automatically centered in the workspace regardless of window dimensions.
  • Granular Zoom: A smooth slider allows custom zoom percentages, along with convenient presets such as "Fit to Window" and quick 100% zoom shortcuts.
