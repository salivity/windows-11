Install Language Packs and Keyboards in Windows 11

This guide explains how to install and configure multiple display language packs and keyboard layouts in Windows 11. You will learn the exact steps required to download new system languages, change the user interface display language, assign different keyboard input methods, and seamlessly toggle between layouts using built-in keyboard shortcuts.

How to Install a New Language Pack

  1. Open the Settings app by pressing Win + I on your keyboard.
  2. Select Time & language from the left-hand navigation menu.
  3. Click on Language & region on the right side.
  4. Under the "Language" section, click the Add a language button.
  5. Search for your desired language in the list and select it, then click Next.
  6. Select your preferred optional features:
    • Language pack: Required to download basic language support.
    • Set as my Windows display language: Check this box if you want Windows menus, settings, and notifications to appear in this language immediately.
    • Text-to-speech, Speech recognition, or Handwriting (optional).
  7. Click Install. Windows will download and install the language files in the background.

How to Change the Windows Display Language

If you have already installed a language pack and want to set it as your primary system language:

  1. Navigate to Settings > Time & language > Language & region.
  2. Locate the Windows display language dropdown menu at the top.
  3. Select your preferred language from the list.
  4. Click Sign out when prompted. The changes will take effect once you sign back into your Windows account.

How to Add a Keyboard Layout to a Language

You can associate multiple keyboard layouts (such as QWERTY, AZERTY, or Dvorak) with a single language.

  1. Go to Settings > Time & language > Language & region.
  2. Find the language you want to modify, click the three dots (...) next to it, and select Language options.
  3. Scroll down to the Keyboards section and click Add a keyboard.
  4. Choose the specific keyboard layout you want to add from the menu.

How to Switch Between Languages and Keyboard Layouts

Once multiple languages or keyboard layouts are installed, an input indicator will appear on the right side of your taskbar next to the clock. You can switch between inputs using either of the following methods:

  • Keyboard Shortcut: Press Windows Key + Spacebar to cycle through your available languages and keyboards, or press Alt + Left Shift.
  • Taskbar Indicator: Click on the three-letter language code on the bottom-right of your taskbar and select the desired layout from the pop-up list.
