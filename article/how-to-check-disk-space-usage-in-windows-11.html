How to Check Disk Space Usage in Windows 11

Windows 11 includes a built-in Storage tool that allows you to analyze hard drive usage, identify large files, and clean up unnecessary data without installing third-party software. This guide covers how to access Windows 11 Storage settings, interpret the breakdown of your disk space across various categories, and locate what is consuming the most capacity on your drives.

Access Storage Settings

  1. Press the Windows Key + I to open the Settings app.
  2. Select System from the left-hand navigation menu.
  3. Click on Storage in the right-hand pane.

Understand the Storage Breakdown

Once inside the Storage menu, Windows 11 displays a visual bar representing your primary drive (usually C:) along with the amount of used and free space. Below the bar, space is categorized to show exactly where data is allocated:

  • Installed Apps: The total space occupied by applications, games, and optional features.
  • Temporary Files: Files generated by apps and the system that are no longer needed, such as previous Windows installation files, thumbnails, and cache.
  • Other: Miscellaneous files, including user-created folders, app data, and third-party program directories not classified elsewhere.
  • System & Reserved: Space reserved for Windows 11 system files, virtual memory (paging files), hibernation files, and system restore points.

To view a complete breakdown, click Show more categories at the bottom of the list.

Drill Down into Specific Categories

To pinpoint large files and reclaim space, select individual categories:

  1. Analyze Installed Apps: Click Installed apps to view all installed software. Use the Sort by dropdown menu at the top and choose Size (Large to small) to immediately identify the largest applications.
  2. Review Temporary Files: Click Temporary files. Windows will scan for items such as the Recycle Bin contents, Downloads folder, and Windows Update Cleanup files. Review the list, select the items you wish to remove, and click Remove files.
  3. Inspect Other and User Files: Click categories such as Documents, Pictures, or Other to view specific folders. Selecting a folder opens File Explorer directly to that directory for manual management.

Analyze Additional Drives

If your computer has multiple storage drives or partitions:

  1. Scroll down to the Storage management section.
  2. Click Advanced storage settings to expand the menu.
  3. Select Storage used on other drives.
  4. Choose any connected drive from the list to view its category breakdown just like the primary drive.
