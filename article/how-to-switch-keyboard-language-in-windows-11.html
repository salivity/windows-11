How to Switch Keyboard Language in Windows 11

Switching keyboard input languages in Windows 11 allows you to seamlessly change typing layouts without interrupting your workflow. Windows 11 provides several built-in shortcuts to toggle between languages on the fly, including the Windows Key + Spacebar combination and traditional hotkeys like Left Alt + Shift. This guide covers the default shortcuts available, how each one works, and how to customize your hotkeys for faster switching.

Default Keyboard Shortcuts to Switch Languages

Windows 11 includes multiple pre-configured shortcuts to switch between installed keyboard layouts and input languages instantly:

  • Windows Key + Spacebar: Press and hold the Windows Key, then press the Spacebar to cycle forward through your installed input languages and layouts. A menu will appear on the right side of your screen showing the active selection. Release both keys to select the highlighted language.
  • Windows Key + Shift + Spacebar: Cycles backward through the list of installed languages.
  • Left Alt + Shift: Immediately switches to the next input language in your list without opening the visual on-screen menu.
  • Ctrl + Shift: Switches between different keyboard layouts assigned to the same input language (for example, switching between US and UK layouts under English).

How to Customize Input Language Hotkeys

If you prefer custom key combinations or want to assign a dedicated shortcut to a specific language, you can configure advanced key sequences:

  1. Press Windows Key + I to open the Settings menu.
  2. Select Time & language from the left sidebar, then click on Typing.
  3. Click on Advanced keyboard settings.
  4. Select Input language hot keys to open the classic Text Services and Input Languages window.
  5. In the Hot keys for input languages list, select Between input languages or select a specific language to assign a direct hotkey.
  6. Click the Change Key Sequence button.
  7. Choose your preferred key combination (such as Ctrl + Shift or Left Alt + Shift) and click OK.
  8. Click Apply and then OK to save your changes.

Adding Languages to Enable Shortcuts

Keyboard shortcuts will only work if you have at least two languages or keyboard layouts installed on your system. To add another language:

  1. Open Settings (Windows Key + I).
  2. Go to Time & language > Language & region.
  3. Click Add a language next to "Preferred languages."
  4. Search for your desired language, select it, and click Next.
  5. Choose your optional language features and click Install.

Once installed, the new language will automatically appear in your language list and can be toggled using any of the shortcuts above.
