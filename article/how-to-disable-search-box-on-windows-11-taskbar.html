How to Disable Search Box on Windows 11 Taskbar

Windows 11 includes a prominent search box on the taskbar by default, which can occupy valuable screen real estate. This guide provides a straightforward, step-by-step walkthrough on how to disable or hide the search box using your system's built-in settings, allowing you to reclaim taskbar space in seconds.

Method 1: Disable via Right-Clicking the Taskbar

  1. Right-click on any empty space on your Windows 11 taskbar.
  2. Select Taskbar settings from the context menu that appears.
  3. In the Settings window that opens, locate the Taskbar items section at the top.
  4. Click the dropdown menu next to the Search option.
  5. Select Hide to completely remove the search box from the taskbar.

Method 2: Disable via Windows Settings

  1. Press the Windows Key + I shortcut on your keyboard to open the Settings app.
  2. Click on Personalization in the left sidebar.
  3. Scroll down and click on Taskbar on the right pane.
  4. Under the Taskbar items section, click the dropdown menu next to Search.
  5. Select Hide.

Alternative Search Options

If you still want access to search without the wide search bar taking up space, you can select these alternative options from the same dropdown menu:

  • Search icon only: Displays a compact magnifying glass icon.
  • Search icon and label: Displays a small icon with the word "Search" next to it.
  • Search box: The default wide input box.

Even with the search box completely hidden, you can still search your PC at any time by pressing the Windows Key and immediately typing your query.
