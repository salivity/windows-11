How to Change Windows 11 Start Menu Layout

Windows 11 allows you to customize the Start Menu layout to better fit your workflow by adjusting the balance between pinned applications and recommended files. This guide walks you through the simple steps to switch between showing more pinned apps, more recommendations, or the default balanced view.

Steps to Change the Start Menu Layout

  1. Open Settings: Press Windows Key + I on your keyboard, or right-click the Start button and select Settings.
  2. Go to Personalization: In the left sidebar, click on Personalization.
  3. Select Start: Scroll down the right pane and click on the Start tile.
  4. Choose Your Layout: At the top of the Start settings page, select one of the three available layout options:
    • More pins: Increases the space for your pinned apps to four rows and reduces the "Recommended" section to a single row.
    • Default: Provides an even split between your pinned apps (three rows) and recommended files (three rows).
    • More recommendations: Increases the "Recommended" section to show more recent files and apps while reducing pinned apps to two rows.

Fine-Tuning the Recommended Section

Below the layout options on the same settings page, you can further customize what appears in the Recommended area using the toggle switches:

  • Show recently added apps: Toggles the display of newly installed software.
  • Show most used apps: Displays the applications you open most frequently.
  • Show recently opened items in Start, Jump Lists, and File Explorer: Controls whether recently viewed files and documents appear in the menu.

Once selected, your changes apply immediately. You can open the Start Menu by clicking the Start button or pressing the Windows Key to preview the new layout.
