How to Use Win + Z for Snap Layouts in Windows 11

The Win + Z keyboard shortcut in Windows 11 provides a fast, mouse-free method to organize open application windows on your screen. By pressing this key combination, Windows triggers the Snap Layouts menu, overlaying numbered zones directly onto the screen so you can arrange windows using sequential keystrokes. This article explains how the shortcut operates, how keyboard navigation works within the menu, and how to ensure the feature is enabled on your system.

How the Win + Z Shortcut Activates Snap Layouts

When you press Win + Z while working in an active window, Windows 11 opens the Snap Layouts visual flyout. Normally accessed by hovering the mouse cursor over a window's Maximize/Restore button, Win + Z instantly brings up this interface via the keyboard.

Depending on your screen resolution and display scaling, the menu displays several predefined grid templates:

  • Two equal zones: Side-by-side split (50/50).
  • Two unequal zones: Main window with a narrower sidebar (70/30 or 80/20).
  • Three zones: One large primary window with two stacked side windows.
  • Four zones: A four-corner equal grid (2x2).

Navigating Snap Layouts with the Keyboard

Once Win + Z triggers the menu, Windows 11 adds visual number badges to the layouts to facilitate complete keyboard navigation:

  1. Select a Layout: Each layout option is assigned a primary number (e.g., 1, 2, 3, or 4). Press the corresponding number on your keyboard to select the desired grid style.
  2. Select a Zone: After choosing a layout, each specific zone within that layout is labeled with a sub-number. Press the number corresponding to the exact area where you want the active window to snap.
  3. Fill Remaining Zones (Snap Assist): Once the active window snaps into place, Snap Assist displays thumbnails of your other open applications in the remaining empty zones. Use your arrow keys to highlight an app and press Enter to place it, or press Esc to leave the zone empty.

Enabling the Feature in Windows Settings

If pressing Win + Z does not bring up the Snap Layouts menu, the feature may be disabled in your system preferences. To turn it on:

  1. Open Settings by pressing Win + I.
  2. Navigate to System > Multitasking.
  3. Toggle the Snap windows switch to On.
  4. Click the dropdown arrow next to Snap windows and verify that the option labeled Show snap layouts when I press the Windows logo key + Z is checked.
