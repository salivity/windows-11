How to Enable VRR, G-Sync, and FreeSync in Windows 11

Variable Refresh Rate (VRR) synchronizes your monitor's refresh rate with your graphics card's frame output to eliminate screen tearing and minimize stuttering. This guide explains how to enable and configure VRR, NVIDIA G-Sync, and AMD FreeSync in Windows 11 using both the operating system settings and dedicated GPU control panels.

1. Prepare Your Hardware and Monitor

Before configuring software settings, ensure your setup supports VRR:

  • Cable Connection: Connect your monitor to your graphics card using a DisplayPort 1.4 (or newer) or HDMI 2.1 cable. DisplayPort is recommended for G-Sync and FreeSync compatibility.
  • Monitor OSD Settings: Open your monitor's On-Screen Display (OSD) menu using the physical buttons on the display. Locate the gaming or display settings and turn on FreeSync, G-Sync, or Adaptive-Sync.

2. Set the Maximum Refresh Rate in Windows 11

Windows must be set to your monitor's highest supported refresh rate for VRR to work effectively:

  1. Open Settings (Win + I) and navigate to System > Display.
  2. Scroll down and click Advanced display.
  3. Under Display information, find Choose a refresh rate and select the highest available value (e.g., 144Hz, 240Hz).

3. Enable Variable Refresh Rate in Windows 11

Windows 11 includes a native VRR toggle for DirectX 11 and DirectX 12 games:

  1. Go to Settings > System > Display.
  2. Scroll down to the Related settings section and click Graphics.
  3. Click Change default graphics settings (or Default graphics settings).
  4. Toggle the switch for Variable refresh rate to On.

4. Configure G-Sync for NVIDIA Graphics Cards

If you have an NVIDIA GPU and a G-Sync or G-Sync Compatible monitor:

  1. Right-click on your desktop and select NVIDIA Control Panel.
  2. In the left sidebar under Display, select Set up G-SYNC.
  3. Check the box for Enable G-SYNC, G-SYNC Compatible.
  4. Choose between Enable for full screen mode or Enable for windowed and full screen mode.
  5. Select your monitor and check Enable settings for the selected display model.
  6. Click Apply at the bottom right.

5. Configure FreeSync for AMD Graphics Cards

If you have an AMD GPU and a FreeSync-compatible monitor:

  1. Right-click on your desktop and select AMD Software: Adrenalin Edition.
  2. Click the Gear icon (Settings) in the top-right corner, then select the Display tab.
  3. If you have multiple displays, select your primary gaming monitor.
  4. Toggle AMD FreeSync to Enabled.

6. Recommended In-Game Settings

To ensure VRR functions properly inside games:

  • V-Sync: Enable V-Sync in the GPU control panel (NVIDIA Control Panel or AMD Software) and disable it inside the in-game settings.
  • Frame Rate Cap: Set a frame rate limit in your GPU driver or game engine to 2–3 FPS below your monitor's maximum refresh rate (e.g., cap at 141 FPS on a 144Hz display) to prevent input lag caused by exceeding the VRR range.
