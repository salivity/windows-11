How to Enable Item Check Boxes in Windows 11

In Windows 11, selecting multiple files and folders can be streamlined by enabling item check boxes in File Explorer. This guide provides a straightforward walkthrough on how to turn on this feature, allowing you to select individual or multiple items easily with a single click or tap without needing to hold down the Ctrl or Shift keys.

Method 1: Enable Check Boxes via the View Menu

The fastest way to toggle check boxes is directly through the File Explorer toolbar:

  1. Press Windows Key + E to open File Explorer.
  2. Click the View menu located on the command bar at the top of the window.
  3. Hover your cursor over the Show submenu at the bottom of the list.
  4. Click on Item check boxes to turn the setting on. A check mark will appear next to the option.

Method 2: Enable Check Boxes via Folder Options

You can also enable item check boxes through the traditional Folder Options menu:

  1. Open File Explorer.
  2. Click the three dots (...) icon (See more) on the top toolbar.
  3. Select Options from the drop-down menu to open Folder Options.
  4. Click on the View tab.
  5. In the Advanced settings list, scroll down and check the box next to Use check boxes to select items.
  6. Click Apply, then click OK to save your changes.

How to Use Item Check Boxes

Once enabled, hovering your mouse pointer over any file, folder, or drive in File Explorer will reveal a small box in the upper-left corner of the item's icon (or next to the file name in Details view). Click the box to select or deselect individual items. You can also select the master check box located in the column header (in Details view) to select all files in the current folder at once.
