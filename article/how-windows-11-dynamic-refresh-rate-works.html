How Windows 11 Dynamic Refresh Rate Works

Dynamic Refresh Rate (DRR) is a Windows 11 feature designed to automatically switch between standard and high display refresh rates based on active screen tasks. By dynamically adjusting the refresh rate between lower frequencies like 60Hz and higher speeds like 120Hz or more, DRR ensures fluid visual motion during interactions like scrolling and writing while conserving critical battery power during static tasks.

The Problem with Fixed High Refresh Rates

Modern laptops and monitors often feature high refresh rate panels (120Hz, 144Hz, or higher) to make system animations, cursor movement, and gaming appear exceptionally smooth. However, running a display at a constant 120Hz or higher demands continuous processing from the GPU and increases the power consumption of the display panel itself. When reading an article, viewing a photo, or typing an email, a constant 120Hz output consumes significant battery life without providing any perceptible visual benefit.

How Dynamic Refresh Rate Manages Display Output

DRR acts as an intelligent intermediary between your hardware and the operating system. Instead of remaining locked at a single frequency, it switches refresh rates seamlessly in real time:

  • Low Power State (60Hz): When the display content is mostly static—such as reading a web page, working in a spreadsheet without moving, or watching standard 24fps–60fps video—Windows drops the refresh rate to 60Hz to reduce GPU load and conserve battery.
  • High Performance State (120Hz+): The moment you interact with the system—such as scrolling through a document, moving a window, or interacting with the stylus—DRR instantly boosts the refresh rate to 120Hz or higher to eliminate motion blur and input lag.
  • Instant Recovery: As soon as interaction stops, the display immediately returns to 60Hz.

Because the transition between rates happens seamlessly without screen flickering or black frames, users perceive the display as consistently smooth while avoiding the power penalty of a permanent high refresh rate.

Key Applications Benefiting from DRR

DRR is deeply integrated into core Windows 11 experiences and supported productivity applications:

  • Digital Inking: When using a stylus on touchscreen devices like the Surface Pro, DRR immediately shifts to 120Hz. This provides near-zero latency and natural pen-on-paper responsiveness, dropping back to 60Hz the moment the pen lifts.
  • Document and Web Scrolling: Applications such as Microsoft Edge, Word, and File Explorer leverage DRR to provide fluid scrolling without stutter, returning to 60Hz as soon as you pause to read.

System Requirements for Dynamic Refresh Rate

To use DRR, your hardware and software must meet specific criteria:

  • Operating System: Windows 11.
  • Display: A panel supporting Variable Refresh Rate (VRR) and a native refresh rate of at least 120Hz.
  • Graphics Driver: A GPU driver that supports Windows Display Driver Model (WDDM) 3.0 or higher.

How to Enable DRR in Windows 11

If your hardware supports DRR, you can enable it through the following steps:

  1. Open Settings and select System.
  2. Click on Display, then navigate to Advanced display.
  3. Under the Choose a refresh rate dropdown menu, select the Dynamic option (e.g., Dynamic (60 Hz or 120 Hz)).
