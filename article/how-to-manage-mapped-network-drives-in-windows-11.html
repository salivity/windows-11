How to Manage Mapped Network Drives in Windows 11

Managing mapped network drives in Windows 11 File Explorer allows you to quickly access shared network folders as if they were local drives. This guide covers the essential steps to map a new network drive, modify existing connections, and disconnect or remove drives directly within the File Explorer interface.

How to Map a New Network Drive

  1. Open File Explorer by pressing Windows Key + E or clicking the folder icon on your taskbar.
  2. Select This PC from the left navigation pane.
  3. Click the three dots (...) (See more) icon on the top command bar.
  4. Select Map network drive from the drop-down menu.
  5. In the configuration window:
    • Choose an available letter in the Drive list.
    • In the Folder field, enter the network path (for example, \\server\share) or click Browse to find it.
    • Check Reconnect at sign-in if you want the drive to automatically mount whenever you start your computer.
    • Check Connect using different credentials if the network folder requires authentication distinct from your current Windows account.
  6. Click Finish. If prompted, enter the network username and password, and check "Remember my credentials" if desired.

How to Access and View Mapped Drives

Once mapped, your network shares appear in File Explorer under This PC in the Network locations section. You can interact with these drives just like standard local partitions:

  • Rename Drive Labels: Right-click the mapped drive, select Rename (or press F2), and type a custom name to identify the share easily.
  • View Properties: Right-click the drive and select Properties to check available storage space, network path details, and file system format.

How to Disconnect a Mapped Network Drive

When you no longer need access to a shared folder or want to free up a drive letter, you can remove it:

  1. Open File Explorer and click This PC.
  2. Locate the drive under Network locations.
  3. Right-click the mapped drive and select Disconnect.

Alternatively, you can click the three dots (...) in the command bar, choose Disconnect network drive, select the drive letter from the list, and click OK.

Reconnecting or Updating Credentials

If a mapped drive shows a red "X" or displays an access denied error:

  1. Double-click the drive to attempt a reconnection.
  2. If credentials have changed, open the Windows Start Menu, search for Credential Manager, and select Windows Credentials.
  3. Locate the server or IP address under Windows Credentials, click Edit, and update the stored username or password.
