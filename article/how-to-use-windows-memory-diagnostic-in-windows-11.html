How to Use Windows Memory Diagnostic in Windows 11

Faulty or failing RAM can lead to frequent crashes, unexpected system freezes, and Blue Screen of Death (BSOD) errors on your PC. Windows 11 includes a built-in utility called Windows Memory Diagnostic that allows you to easily scan your physical memory modules for hardware defects. This guide provides a step-by-step walkthrough on how to launch the tool, run the diagnostic scan, and interpret the test results.

How to Open and Run Windows Memory Diagnostic

To launch the tool and begin testing your memory, follow these steps:

  1. Press Windows Key + R to open the Run dialog box.
  2. Type mdsched.exe and press Enter (or click OK). Alternatively, search for Windows Memory Diagnostic in the Start menu and select it.
  3. A prompt will appear offering two choices:
    • Restart now and check for problems (recommended): This immediately restarts your computer and begins the memory scan. Ensure you save all open work before clicking this option.
    • Check for problems the next time I start my computer: This schedules the scan to run the next time you turn on or manually restart your PC.

The Memory Test Process

Once your computer restarts, it will boot directly into the blue Windows Memory Diagnostic screen.

  • The tool runs automatically using the Standard test configuration, which performs a series of read/write passes on your RAM modules.
  • A progress bar will show the overall completion percentage and whether any hardware errors have been detected so far.
  • If you want to change the test options, press F1 on your keyboard to switch between Basic, Standard, and Extended test mixes, adjust the cache settings, or increase the number of passes. Press F10 to apply changes.
  • After the test finishes, your computer will reboot back into Windows 11 automatically.

How to View the Diagnostic Results

After Windows loads, a notification should appear in the System Tray detailing the results of the scan. If the notification does not appear, you can check the results manually using the Event Viewer:

  1. Right-click the Start button and select Event Viewer (or press Win + X and select it from the menu).
  2. In the left pane, expand Windows Logs and select System.
  3. In the right pane, click Filter Current Log...
  4. In the Event sources dropdown menu, scroll down, check the box next to MemoryDiagnostics-Results, and click OK.
  5. Look for the most recent log entries in the middle pane. Double-click an entry to read the detailed report.

If the report indicates errors, your RAM is likely defective or improperly seated, and the affected memory stick may need to be reseated in its slot or replaced.
