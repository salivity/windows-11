How to Safely Delete Windows.old in Windows 11

When you upgrade to Windows 11, the operating system automatically creates a Windows.old folder to store your previous system files in case you want to roll back. If your system is stable and you need to free up dozens of gigabytes of disk space, you can safely remove this directory. This guide provides the quickest and safest methods to remove the Windows.old folder using built-in Windows 11 tools.

Why You Shouldn't Just Press "Delete"

Do not try to delete the Windows.old folder directly from File Explorer. Because it contains protected system files and specific access permissions, attempting to delete it manually will usually result in "Access Denied" errors. Use the official system cleanup tools outlined below instead.

Method 1: Use Windows 11 Settings (Recommended)

  1. Open the Settings app by pressing Win + I.
  2. Navigate to System > Storage.
  3. Under the storage breakdown, click on Temporary files.
  4. Wait for Windows to scan your drive.
  5. Look through the list and check the box next to Previous Windows installation(s).
  6. Uncheck any items you want to keep (such as your Downloads folder).
  7. Scroll back up and click the Remove files button.

Method 2: Use Disk Cleanup

  1. Press the Windows Key, type Disk Cleanup, and press Enter.
  2. Select the drive where Windows is installed (usually the C: drive) and click OK.
  3. Click the Clean up system files button near the bottom. (Provide administrator permission if prompted).
  4. Select the C: drive again and click OK.
  5. In the Files to delete list, check Previous Windows installation(s).
  6. Click OK, then click Delete Files to confirm.

Method 3: Use Storage Sense for Automatic Cleanup

Windows 11 will automatically delete the Windows.old folder after 10 days. If you want Storage Sense to handle it immediately:

  1. Go to Settings > System > Storage.
  2. Click on Storage Sense.
  3. Toggle Storage Sense to On.
  4. Scroll to the bottom and click Run Storage Sense now.
