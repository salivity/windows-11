Windows 11 Voice Access: Mouse Grid and Navigation

Windows 11 includes Voice Access, an accessibility feature designed to let users control their entire PC using only spoken commands. This article explains how Voice Access facilitates seamless application navigation, window management, and precise on-screen interactions through its intuitive mouse grid system, providing a completely hands-free computing experience.

Setting Up Voice Access

To enable Voice Access in Windows 11:

  1. Open Settings by pressing Win + I.
  2. Navigate to Accessibility and select Speech.
  3. Toggle the Voice access switch to On.
  4. Alternatively, search for "Voice access" in the Start menu or use the shortcut Alt + Shift + C once configured.

Upon first launch, you will be prompted to download an offline speech model and set up your microphone.

Navigating Apps with Voice Commands

Voice Access allows you to launch, manage, and interact with applications using natural phrases:

  • Opening and Closing Apps: Say "Open [App Name]" (e.g., "Open Notepad") to launch software, and "Close [App Name]" or "Close window" to exit.
  • Switching Between Apps: Use commands like "Switch to [App Name]" or "Show Task View" to move between active windows.
  • Window Management: Control your workspace by saying "Maximize window," "Minimize window," or "Snap window left."
  • Interacting with UI Elements: Speak the exact name of a visible button or link to click it, such as "Click Search" or "Click File."
  • Number Overlays: If an element does not have a clear text label, say "Show numbers." Voice Access places numbered badges over every interactive item on the screen. Say the corresponding number to click that specific element.
  • Scrolling: Scroll through web pages and documents using commands like "Scroll down," "Scroll up," or "Scroll to top."

Controlling the Mouse with Voice Access

For actions that require direct cursor placement, Voice Access provides dedicated mouse control tools, primarily through the Mouse Grid.

Using the Mouse Grid

The mouse grid overlays a numbered 3x3 grid across your screen or active window, allowing you to pinpoint coordinates down to the exact pixel.

  1. Activate the Grid: Say "Mouse grid" to display a nine-box grid across the entire display, or say "Show mouse grid on [window/app name]" to confine it to a specific program.
  2. Narrow the Target: Speak the number of the quadrant where your target element is located. The grid zooms into that specific box and generates another 3x3 sub-grid.
  3. Repeat for Precision: Continue saying numbers until the cursor is positioned precisely over the target item.
  4. Execute an Action: Once the cursor is positioned, use standard mouse actions:
    • "Click" (left-click)
    • "Double click"
    • "Right click"
    • "Middle click"
  5. Dismiss the Grid: Say "Cancel" or "Hide grid" at any time to remove the overlay without taking an action.

Drag and Drop Operations

You can perform drag-and-drop actions with the mouse grid:

  1. Position the cursor over the item you want to move using the mouse grid.
  2. Say "Mark [Number]" or activate the drag state.
  3. Call up the mouse grid again to select the destination.
  4. Say "Drop" to release the item at the selected location.

Essential System Commands

  • "Voice access wake up" / "Unmute": Starts listening.
  • "Voice access sleep" / "Mute": Pauses listening.
  • "Turn off voice access": Closes the tool completely.
  • "What can I say?": Opens a menu of available commands based on your current screen context.
