Schedule CHKDSK on Next Reboot in Windows 11

The Check Disk (CHKDSK) utility in Windows 11 is an essential built-in tool used to inspect the integrity of your file system and fix logical disk errors or bad sectors. When scanning a drive currently in use by the operating system (such as the primary C: drive), Windows cannot lock the volume immediately and must perform the scan during the system boot sequence. This guide demonstrates how to schedule a CHKDSK volume scan to run automatically upon your next Windows 11 restart using the Command Prompt, Windows PowerShell, and File Explorer.

Method 1: Schedule CHKDSK Using Command Prompt

Using the Command Prompt with administrative privileges is the fastest and most reliable method to schedule a disk check.

  1. Click the Start button or press the Windows Key.
  2. Type cmd in the search bar.
  3. Right-click on Command Prompt and select Run as administrator (or click Run as administrator in the right pane).
  4. In the elevated Command Prompt window, type the following command and press Enter: 
    chkdsk C: /f /r
    (Note: Replace C: with your target drive letter if scanning a different partition.)
  5. The system will display a prompt: Chkdsk cannot run because the volume is in use by another process. Would you like to schedule this volume to be checked the next time the system restarts? (Y/N)
  6. Type Y and press Enter.
  7. Restart your computer. The CHKDSK utility will automatically execute before Windows 11 loads to scan and repair the drive.

Key CHKDSK Parameters:

  • /f: Fixes errors detected on the disk.
  • /r: Locates bad sectors and recovers readable information (implies /f).
  • /x: Forces the volume to dismount first if necessary.

Method 2: Schedule CHKDSK Using Windows PowerShell

You can also use PowerShell to schedule a scan with administrative rights.

  1. Press Windows Key + X to open the Quick Link menu.
  2. Select Terminal (Admin) or Windows PowerShell (Admin).
  3. Enter the scan command: 
    chkdsk C: /f
  4. When prompted with (Y/N), type Y and press Enter.
  5. Restart your PC to begin the scheduled scan.

Method 3: Schedule CHKDSK via File Explorer

Windows 11 also provides a graphical interface to check drives and schedule repairs.

  1. Open File Explorer (press Windows Key + E).
  2. Click on This PC in the left sidebar.
  3. Under Devices and drives, right-click the drive you want to scan (e.g., Local Disk (C:)) and select Properties.
  4. Switch to the Tools tab.
  5. In the Error checking section, click the Check button.
  6. If the drive is in use, click Scan drive or Repair drive.
  7. If errors are found or the drive needs exclusive access, choose the option to restart immediately or schedule the repair on the next restart.

How to Cancel a Scheduled CHKDSK Scan

If you decide not to run the scheduled disk check on the next restart, you can cancel it via the Command Prompt:

  1. Open Command Prompt as an administrator.
  2. Type the following command and press Enter: 
    chkntfs /x C:
    (Replace C: with the appropriate drive letter.)
  3. This command modifies the boot settings to exclude the specified drive from the automatic boot-time check.
