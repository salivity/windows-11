How to Customize Windows 11 Start Menu Quick Folders

Windows 11 allows users to personalize the Start menu by placing convenient shortcut icons directly next to the Power button at the bottom of the menu. This guide provides a straightforward walkthrough on how to access the personalization settings and choose exactly which quick folders—such as Settings, File Explorer, Downloads, Documents, and Network—appear next to your power options for faster navigation.

Steps to Customize Start Menu Quick Folders

  1. Open Windows Settings Press the keyboard shortcut Windows Key + I, or right-click the Start button and select Settings from the menu.

  2. Go to Personalization In the left-hand navigation pane, click on Personalization.

  3. Select Start Menu Options Scroll down the right pane and click on the Start section.

  4. Open the Folders Menu Click on the Folders option located under the Start settings.

  5. Toggle Your Desired Folder Shortcuts You will see a list of available shortcuts. Toggle the switch to On for any item you want to appear next to the power button, or Off to remove it. The available options include:

    • Settings
    • File Explorer
    • Documents
    • Downloads
    • Music
    • Pictures
    • Videos
    • Network
    • Personal folder (User profile directory)

  6. Verify the Changes Open the Start menu. The enabled folders will immediately appear as small icons directly to the left of the Power icon in the bottom-right corner of the Start menu interface.
