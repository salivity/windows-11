Map Controller to Mouse and Keyboard in Windows 11

Mapping a game controller to emulate mouse and keyboard inputs allows you to navigate Windows 11, manage desktop applications, and play non-controller-supported PC games entirely from a gamepad. Windows 11 supports native controller configuration through Microsoft's official Xbox Accessories ecosystem and built-in accessibility settings. This guide explains how to configure your controller buttons to trigger keyboard presses and mouse actions directly in Windows 11.

Method 1: Use the Xbox Accessories App

The Xbox Accessories app is Microsoft’s official utility for configuring Xbox Wireless Controllers, Xbox Elite Series 2 controllers, and Xbox Adaptive Controllers in Windows 11.

  1. Install and Launch the App:
    • Open the Start Menu, search for Xbox Accessories, and open it. (If it is not installed, download it for free from the Microsoft Store).
  2. Connect Your Controller:
    • Plug your controller in via USB-C or connect it via Bluetooth through Settings > Bluetooth & devices.
  3. Create a Configuration Profile:
    • Click the Configure button beneath your connected controller.
    • Click New Profile and assign it a name (e.g., "Desktop Mode").
  4. Map Buttons to Keyboard Keys:
    • Select the button you wish to remap (e.g., the A button or a paddle).
    • Choose Key from the mapping dropdown menu.
    • Press the physical keyboard key you want assigned to that button (e.g., Space, Enter, or Ctrl).
    • Repeat this step for each button you want to map to keyboard keys or system shortcuts.
  5. Apply the Profile:
    • Save the configuration and assign it to an active slot on your controller.

Note: Full keyboard mapping inside the Xbox Accessories app is supported on the Xbox Elite Wireless Controller Series 2 and the Xbox Adaptive Controller.

Method 2: Enable Windows 11 Controller Desktop Navigation

Windows 11 includes native gamepad navigation features that allow you to control system elements and text entry without third-party drivers.

Use the Gamepad as a Virtual Mouse and Keyboard

  1. Open the Touch Keyboard via Controller:
    • Press the Xbox Button (or guide button) on your controller to open the Windows Game Bar.
    • Navigate to the Touch Keyboard widget on the Game Bar to enter text into any active Windows text field using your controller's directional pad or thumbsticks.
  2. Navigate System Windows:
    • The primary directional pad (D-Pad) and Left Stick naturally control focus across Windows 11 menus, Taskbar icons, and File Explorer.
    • The A button functions as Enter (left-click equivalent), and the B button functions as Esc or Back.

Method 3: Use Windows 11 Mouse Keys and Accessibility

If you require analog cursor movement mapped to hardware keys natively:

  1. Open Settings on Windows 11 (Win + I).
  2. Navigate to Accessibility > Mouse.
  3. Toggle Mouse Keys to On.
  4. Combine this with standard controller remapping in the Xbox Accessories app to control the numeric keypad shortcuts that move the mouse cursor across the screen.
