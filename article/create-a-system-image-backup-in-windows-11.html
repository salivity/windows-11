Create a System Image Backup in Windows 11

Creating a full-system image backup in Windows 11 allows you to capture an exact snapshot of your entire operating system, including your settings, installed applications, system files, and personal data. This guide walks you through using the native legacy utility—Backup and Restore (Windows 7)—which remains fully functional in Windows 11 for complete disaster recovery without needing third-party software.

Step 1: Connect Your Backup Drive

Connect an external hard drive or SSD with sufficient free storage to hold the entire contents of your Windows 11 installation drive.

Step 2: Open Backup and Restore (Windows 7)

  1. Press the Windows Key, type Control Panel, and press Enter.
  2. In the top-right corner of the Control Panel, set View by to Large icons or Small icons.
  3. Click on Backup and Restore (Windows 7).

Step 3: Launch the System Image Wizard

  1. In the left navigation pane, click the Create a system image link.
  2. The wizard will scan your system for available backup devices.

Step 4: Select Your Backup Destination

Choose where you want to save the backup:

  • On a hard disk: Select your connected external drive from the dropdown menu (recommended).
  • On a network location: Click Select to enter a network share path and login credentials.

Click Next to proceed.

Step 5: Confirm and Start the Backup

  1. The wizard will automatically select the partitions required to run Windows (such as the EFI System Partition, the C: drive, and the Windows Recovery Environment).
  2. You can optionally check the boxes for any additional internal drives you wish to include.
  3. Review your backup settings and the estimated size required.
  4. Click Start backup.

Windows 11 will begin creating the system image. The process may take anywhere from a few minutes to several hours depending on the amount of data and drive speed. Once finished, you will be prompted to create a System Repair Disc; if your PC lacks an optical drive, you can skip this and use a standard Windows 11 installation USB media for recovery instead.
