Change Default PDF and Media Player in Windows 11

Configuring your default applications in Windows 11 ensures that your preferred software automatically opens specific document and media formats. This guide provides a direct, step-by-step walkthrough for setting your default PDF reader and media player using both the Windows Settings application and the File Explorer context menu.

Method 1: Using Windows 11 Settings

The Settings app provides a centralized interface to manage default file associations for any program.

Setting the Default PDF Reader

  1. Press Windows Key + I to open the Settings menu.
  2. Select Apps from the left sidebar, then click on Default apps.
  3. In the search box labeled Set a default for a file type or link type, type .pdf.
  4. Click on the current default application (often Microsoft Edge) displayed under the search result.
  5. Select your preferred PDF reader (such as Adobe Acrobat, Foxit Reader, or a web browser) from the list.
  6. Click Set default.

Setting the Default Media Player

  1. Open Settings (Windows Key + I) and navigate to Apps > Default apps.
  2. Scroll down through the list of installed applications and click on your preferred media player (e.g., VLC Media Player, Windows Media Player, or Spotify).
  3. You will see a list of file extensions (such as .mp4, .mkv, .mp3, and .wav).
  4. Click on the file extension you want to reassign.
  5. Choose your desired media player from the pop-up list and click Set default.
  6. Repeat this for any other audio or video formats you wish to associate with that player.

Method 2: Using the Right-Click Context Menu

You can quickly assign a default handler directly from any saved file on your computer.

  1. Locate a .pdf, audio, or video file in File Explorer.
  2. Right-click the file and hover over Open with.
  3. Select Choose another app from the submenu.
  4. Highlight your preferred program from the list.
  5. Click the Always button at the bottom of the window to permanently set this application as the default handler for that file extension.
