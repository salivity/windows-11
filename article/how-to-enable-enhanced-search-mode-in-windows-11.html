How to Enable Enhanced Search Mode in Windows 11

Windows 11 includes an Enhanced Search indexing feature that expands file searches beyond default user libraries to scan all connected hard drives, partitions, and folders on your PC. This guide explains how to enable Enhanced Search mode in Windows 11, configure excluded folders, and optimize system indexing so you can quickly locate any file across all your drives.

Steps to Configure Enhanced Search in Windows 11

  1. Open Windows Settings: Press the keyboard shortcut Windows Key + I or click the Start button and select the Settings gear icon.
  2. Navigate to Search Settings: In the left sidebar, select Privacy & security, then click on Searching Windows in the right-hand pane.
  3. Select Enhanced Search: Under the Find my files section, switch the selection from Classic to Enhanced.

Managing Excluded Folders

By default, Enhanced Search excludes certain system and temporary directories to prevent indexing clutter and conserve system resources. To ensure all desired drives and directories are included:

  1. Look under the Exclude folders section on the same Searching Windows settings page.
  2. Review the list of excluded paths. If an entire drive or a specific partition you want to index is listed, click the three dots (...) next to the folder/drive and select Remove.
  3. To exclude folders you do not need to search (such as large game installations or backup folders), click the Add an excluded folder button and select the directory.

Indexing Status and Performance Notes

  • Initial Indexing Time: Once Enhanced Search is enabled, Windows will begin indexing all files across your drives. This process can take several hours depending on the total storage size and the number of files.
  • Power Constraints: Windows automatically pauses or slows indexing when running on battery power to conserve energy. Connect your device to a power source for faster initial indexing.
  • Advanced Indexing: For granular control over file properties and file contents indexing, click Advanced indexing options at the bottom of the Searching Windows page.
