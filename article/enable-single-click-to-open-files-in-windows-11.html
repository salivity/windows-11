Enable Single-Click to Open Files in Windows 11

By default, Windows 11 requires you to double-click files and folders to open them. However, you can change this behavior to a single click, allowing you to open items just like links on a web page. This guide provides a straightforward, step-by-step walkthrough to help you switch from the default double-click setting to single-click navigation in Windows 11 File Explorer.

Steps to Enable Single-Click in Windows 11

  1. Open File Explorer Press the keyboard shortcut Windows Key + E, or click the File Explorer icon on your taskbar.

  2. Access Folder Options In the top menu bar of File Explorer, click the three dots (...) (See more) icon located on the far right, then select Options from the drop-down menu.

  3. Navigate to the General Tab The Folder Options window will open directly to the General tab.

  4. Change the Click Setting Look for the section labeled Click items as follows. Select the radio button for Single-click to open an item (point to select).

  5. Choose an Underline Preference Once you select single-click, choose one of the two underline sub-options:

    • Underline icon titles consistent with my browser: Keeps all file and folder names underlined constantly.
    • Underline icon titles only when I point at them: Underlines a file or folder name only when you hover your mouse cursor over it.

  6. Save Changes Click Apply at the bottom of the window, and then click OK.

How Single-Click Navigation Works

  • To Select an Item: Hover your mouse cursor over the file or folder for a brief moment without clicking.
  • To Open an Item: Click the file or folder once with the left mouse button.
  • To Select Multiple Items: Hold down the Ctrl key and hover over each item you want to select, or click the checkboxes next to the files if item check boxes are enabled.

To revert to the default behavior at any time, return to the Folder Options menu and select Double-click to open an item (single-click to select).
