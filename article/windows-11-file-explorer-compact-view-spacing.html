Windows 11 File Explorer Compact View Spacing

Windows 11 introduced a redesigned File Explorer featuring larger padding between files and folders to improve usability on touch-screen devices. However, this added spacing decreases the number of items visible on standard desktop screens. To address this, Microsoft included a "Compact View" mode that reduces vertical spacing and restores a denser, traditional layout. This article explains how Windows 11 manages this spacing behavior and outlines the exact steps to enable or disable Compact View.

Understanding Default Spacing vs. Compact View

By default, Windows 11 applies modern spacing to items within File Explorer. This design adds noticeable padding around rows, icons, and text. While beneficial for tablet users and touch navigation, it requires desktop and laptop users with mouse inputs to scroll significantly more to browse large directories.

Compact View resolves this by stripping away the extra vertical padding. When activated, items are arranged closely together, mimicking the information density found in Windows 10. This layout allows more files, folders, and metadata columns to fit within a single window view without altering icon sizes or thumbnail previews.

How to Enable Compact View via the Command Bar

The quickest method to toggle item spacing is directly through the File Explorer command bar:

  1. Open File Explorer (or press Win + E).
  2. Click the View menu located on the top command bar.
  3. Click on Compact view in the drop-down menu.

A checkmark will appear next to the option, and the current folder will immediately update with reduced row spacing.

How to Enable Compact View via Folder Options

You can also control the spacing setting through the classic Folder Options dialogue:

  1. In File Explorer, click the three-dot menu (...) (See more) on the command bar.
  2. Select Options to open the Folder Options window.
  3. Navigate to the View tab.
  4. Under the Advanced settings list, check the box labeled Decrease space between items (compact view).
  5. Click Apply, then click OK.

Scope and Behavior

Compact View is a global system setting in Windows 11. Once enabled, the reduced spacing applies automatically across all folder locations, library folders, and search results. The configuration persists across system reboots and stays tied to your user profile until manually changed back.
