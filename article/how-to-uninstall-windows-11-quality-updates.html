How to Uninstall Windows 11 Quality Updates

Windows 11 quality updates provide critical security patches and bug fixes, but they can occasionally cause system instability, driver conflicts, or software crashes. This guide provides step-by-step instructions to safely remove a problematic quality update from your Windows 11 PC using the Settings app, Command Prompt, or the Windows Recovery Environment if your system fails to boot normally.

Method 1: Uninstall via Windows Settings

The easiest way to remove an update is directly through the Windows 11 Settings menu.

  1. Open Settings by pressing Windows Key + I.
  2. Click on Windows Update in the left sidebar.
  3. Select Update history from the main pane.
  4. Scroll down to the Related settings section and click Uninstall updates.
  5. Locate the specific quality update (usually labeled with a KB number) causing issues.
  6. Click the Uninstall button next to the update and confirm your choice.
  7. Restart your computer to complete the removal.

Method 2: Uninstall via Command Prompt

If the Settings app is unresponsive or you prefer using command-line tools, you can use the Windows Update Standalone Installer (wusa).

  1. Press Windows Key + S, type cmd, right-click Command Prompt, and select Run as administrator.
  2. To view recently installed updates and their KB numbers, enter: 
    wmic qfe list brief /format:table
  3. Run the following command to uninstall the update (replace [KBNumber] with the actual number, e.g., 5034441): 
    wusa /uninstall /kb:[KBNumber] /promptrestart
  4. Confirm the prompt when asked to proceed and allow your computer to restart.

Method 3: Uninstall via Advanced Startup (If PC Won't Boot)

If the update causes a blue screen (BSOD) or prevents Windows from loading:

  1. Turn on your PC, and as soon as Windows begins loading, hold the power button to force a shutdown. Repeat this twice to trigger Automatic Repair.
  2. Select Advanced options on the Automatic Repair screen to enter the Windows Recovery Environment (WinRE).
  3. Navigate to Troubleshoot > Advanced options.
  4. Select Uninstall Updates.
  5. Choose Uninstall latest quality update.
  6. Select your user account, enter your password, and click Uninstall quality update.
  7. Once finished, click Done and select Continue to boot into Windows 11.

How to Prevent the Update from Reinstalling

Windows Update will attempt to reinstall the removed update during the next update cycle. To temporarily prevent this:

  1. Go to Settings > Windows Update.
  2. Under Pause updates, choose to pause updates for 1 to 5 weeks, giving Microsoft time to release a fix for the issue.
