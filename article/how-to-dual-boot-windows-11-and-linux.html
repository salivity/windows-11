How to Dual Boot Windows 11 and Linux

Configuring a dual-boot system allows you to run Windows 11 and a Linux distribution on the same machine, giving you the flexibility to choose your operating system at startup. This guide covers the essential steps to prepare your hardware, partition your storage drive safely within Windows, install your chosen Linux distribution, and manage the bootloader to ensure seamless switching between systems.

Step 1: Prepare Windows 11 and Backup Data

  1. Back Up Important Files: Modifying disk partitions carries a risk of data loss. Back up your essential files to an external drive or cloud storage before proceeding.
  2. Disable BitLocker: If BitLocker Drive Encryption is enabled on Windows 11, suspend or turn it off to prevent partition-locking issues during the Linux installation.
  3. Disable Fast Startup:
    • Open the Control Panel and navigate to Power Options.
    • Click Choose what the power buttons do.
    • Click Change settings that are currently unavailable.
    • Uncheck Turn on fast startup (recommended) and save changes.

Step 2: Create Unallocated Disk Space

  1. Press Win + X and select Disk Management.
  2. Locate your primary Windows partition (usually the C: drive).
  3. Right-click the partition and select Shrink Volume.
  4. Enter the amount of space you want to allocate for Linux (a minimum of 50 GB / 51200 MB is recommended).
  5. Click Shrink. Leave the newly created space as Unallocated; do not format it.

Step 3: Create Bootable Linux Media

  1. Download the ISO image of your chosen Linux distribution (e.g., Ubuntu, Fedora, or Linux Mint).
  2. Download a USB flashing tool such as Rufus or BalenaEtcher.
  3. Insert a USB flash drive (at least 8 GB) and write the ISO to the drive using the flashing tool in UEFI/GPT mode.

Step 4: Adjust UEFI/BIOS Settings

  1. Restart your PC and press the manufacturer's BIOS/UEFI key (commonly F2, F12, Del, or Esc).
  2. Verify that UEFI Mode is enabled.
  3. Disable Secure Boot if your chosen distribution does not officially support it (most modern distributions like Ubuntu and Fedora support Secure Boot, but disabling it prevents driver conflicts).
  4. Change the boot order to place your USB flash drive as the primary boot device, then save and exit.

Step 5: Install Linux Alongside Windows 11

  1. Boot into the Linux live environment from the USB drive.
  2. Launch the installer from the desktop.
  3. Proceed through language, keyboard, and network settings.
  4. When prompted for the installation type:
    • Automatic Method: Select Install alongside Windows Boot Manager. The installer will automatically use the unallocated space created in Step 2.
    • Manual Method (Something Else / Custom): Create an EFI partition (or select the existing Windows EFI system partition), an ext4 root partition (/), and optionally a swap partition within the unallocated space.
  5. Set your username, computer name, and password.
  6. Complete the installation and restart your computer when prompted, removing the USB drive.

Step 6: Configure and Test the Bootloader

Upon restarting, the GRUB bootloader menu should appear automatically, offering options to boot into either your Linux distribution or the Windows Boot Manager.

If the system boots directly into Windows 11 without displaying the GRUB menu:

  1. Restart and enter the UEFI/BIOS settings.
  2. Navigate to the Boot tab and set the Linux bootloader (e.g., ubuntu or grub) as the first boot priority.
  3. Save changes and reboot.
