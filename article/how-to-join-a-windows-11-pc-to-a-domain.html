How to Join a Windows 11 PC to a Domain

This guide provides a direct, step-by-step walkthrough on how to connect a computer running Windows 11 Pro or Enterprise to a corporate Active Directory domain controller network. Joining a domain allows organizations to centrally manage user accounts, enforce security policies, and grant seamless access to shared network resources such as file servers, printers, and internal applications.

Prerequisites Before Joining

Before attempting to join the domain, ensure the following requirements are met:

  • Operating System: Windows 11 Pro, Enterprise, or Education (Windows 11 Home does not support domain joining).
  • Network Connectivity: The PC must be connected directly to the corporate network via Ethernet, internal Wi-Fi, or a pre-logon corporate VPN.
  • DNS Configuration: The network adapter's primary DNS must point directly to the domain controller or internal corporate DNS server.
  • Credentials: A domain user account with permissions to join a computer to the Active Directory domain.
  • Domain Name: The fully qualified domain name (FQDN), such as corp.domain.com.

Method 1: Join via Windows 11 Settings (Recommended)

  1. Open Settings by pressing Windows Key + I.
  2. Navigate to Accounts on the left menu, then select Access work or school.
  3. Click the Connect button next to Add a work or school account.
  4. In the pop-up window, do not enter an email address. Instead, click the link at the bottom: Join this device to a local Active Directory domain.
  5. Enter the Domain name (FQDN) in the text box and click Next.
  6. Enter the Username and Password of a domain account authorized to join devices to the domain, then click OK.
  7. You will be prompted to add an account to use the PC. You can skip this or add a domain user, then click Next.
  8. Click Restart now to complete the domain join process.

Method 2: Join via System Properties (Classic)

  1. Press Windows Key + R to open the Run dialog box.
  2. Type sysdm.cpl and press Enter to open System Properties.
  3. Under the Computer Name tab, click the Change... button.
  4. In the Member of section at the bottom, select the Domain radio button.
  5. Type the corporate domain name into the box and click OK.
  6. When prompted, enter the credentials of an authorized domain user or administrator and click OK.
  7. A message will appear stating: "Welcome to the [Domain Name] domain." Click OK.
  8. Click OK on the restart notification, close the System Properties window, and click Restart Now.

Logging In After Restart

  1. On the Windows 11 sign-in screen, click Other user in the lower-left corner.
  2. Enter your domain username in one of the following formats:
    • DOMAIN\username
    • username@domain.com
  3. Enter your domain password and press Enter to sign in to your new domain profile.
