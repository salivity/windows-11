How to Use Microsoft Print to PDF in Windows 11

Windows 11 includes a built-in virtual printer called Microsoft Print to PDF, which allows you to convert any printable document, image, or web page into a high-quality PDF file without installing third-party software. This article outlines the step-by-step process for using this native tool in any Windows 11 application, along with instructions on how to re-enable the feature if it is missing from your system.

Steps to Print to a PDF File

You can use the Microsoft Print to PDF feature from any application that supports standard printing, such as Microsoft Word, web browsers (Chrome, Edge, Firefox), Notepad, or Photo Viewer.

  1. Open the Document: Open the file, image, or web page you want to convert.
  2. Open the Print Dialog:
    • Press Ctrl + P on your keyboard, or
    • Click File in the top menu and select Print.
  3. Select the Printer: In the printer selection dropdown menu, choose Microsoft Print to PDF.
  4. Adjust Print Settings (Optional):
    • Choose your preferred orientation (Portrait or Landscape).
    • Specify the page range (All, Current Page, or Custom Range).
    • Adjust margins, scale, and color settings if needed.
  5. Print the Document: Click the Print button at the bottom of the dialog box.
  6. Save the PDF:
    • A "Save Print Output As" window will appear.
    • Navigate to the folder where you want to save the file.
    • Enter a name for your PDF in the File name field.
    • Click Save.

Your new PDF document is now created and saved to your selected location.

How to Enable Microsoft Print to PDF if Missing

If Microsoft Print to PDF does not appear in your list of available printers, it may be turned off in your Windows features. Follow these steps to restore it:

  1. Press Windows Key + R, type optionalfeatures, and press Enter.
  2. In the Windows Features window, scroll down and find Microsoft Print to PDF.
  3. Check the box next to Microsoft Print to PDF. (If it is already checked, uncheck it, click OK, reopen the window, and check it again to reset the feature.)
  4. Click OK and wait for Windows to apply the changes.
  5. Restart your open applications to see the printer listed.
