How to Configure ICC Color Profiles in Windows 11

Configuring custom ICC (International Color Consortium) display profiles in Windows 11 ensures that your monitor reproduces colors accurately for photo editing, graphic design, and general viewing. This guide walks you through downloading, installing, and assigning a custom .icc or .icm color profile to your specific monitor using the built-in Windows 11 Color Management tool.

Step 1: Open the Color Management Tool

  1. Press Windows Key + S to open the search bar.
  2. Type Color Management and press Enter, or press Windows Key + R, type colorcpl, and hit Enter.

Step 2: Select Your Display

  1. In the Color Management window, click on the Devices tab.
  2. Click the Device drop-down menu and choose the monitor you want to calibrate.
  3. Check the box labeled Use my settings for this device.

Step 3: Add the Custom ICC Profile

  1. Click the Add... button at the bottom of the window.
  2. In the Associate Color Profile window, click the Browse... button.
  3. Navigate to the folder where your .icc or .icm file is saved.
  4. Select your custom profile and click Add.

Step 4: Set the Profile as Default

  1. Under the Profiles associated with this device list, select the newly added ICC profile.
  2. Click the Set as Default Profile button.
  3. Click Close to save your changes and exit the tool.

Step 5: Apply System-Wide (Optional)

If you want the color profile applied to all user accounts on the computer:

  1. In the Color Management window, go to the Advanced tab.
  2. Click Change system defaults....
  3. In the new window, select your monitor, check Use my settings for this device, add the ICC profile, and set it as the default.
  4. Close both windows.
