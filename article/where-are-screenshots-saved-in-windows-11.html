Where Are Screenshots Saved in Windows 11?

In Windows 11, the default storage location for screenshots depends directly on the method or keyboard shortcut used to capture your screen. While the standard shortcut automatically saves images to a dedicated folder inside your user profile's Pictures directory, other built-in tools like the Snipping Tool, Xbox Game Bar, and OneDrive utilize different locations. This guide outlines the exact default file paths for each capture method and explains how to quickly access or change these folders.

Default Screenshot Folder (Win + Print Screen)

When you capture your entire screen by pressing Windows Key + PrtScn (or Windows Key + Fn + PrtScn on some laptops), Windows automatically generates an image file in PNG format and saves it without requiring you to open an image editor.

The default file path is: C:\Users\<YourUsername>\Pictures\Screenshots

To open this location quickly:

  1. Press Windows Key + E to open File Explorer.
  2. In the left navigation pane, select Pictures (or navigate to This PC > Pictures).
  3. Open the Screenshots folder.

Snipping Tool Saves (Win + Shift + S)

When using the keyboard shortcut Windows Key + Shift + S to open the Snipping Tool:

  • By default, the capture is copied directly to your clipboard so you can paste it into any application with Ctrl + V.
  • In Windows 11, the updated Snipping Tool also automatically saves a copy to the same default directory: C:\Users\<YourUsername>\Pictures\Screenshots.
  • If automatic saving is turned off, the screenshot will only reside in your clipboard until you click the preview banner and manually save it to a destination of your choice.

Xbox Game Bar Screenshots (Win + Alt + PrtScn)

If you use the Xbox Game Bar overlay or press Windows Key + Alt + PrtScn to capture gaming clips or still screenshots, Windows 11 directs these files to your video library rather than the pictures library.

The default file path is: C:\Users\<YourUsername>\Videos\Captures

OneDrive Synced Screenshots

If you have Microsoft OneDrive installed and configured to automatically save screen captures to the cloud, the path shifts from the local drive to your OneDrive directory.

The OneDrive file path is: C:\Users\<YourUsername>\OneDrive\Pictures\Screenshots

How to Change the Default Screenshot Location

If you want to store your automated captures on a different drive or folder:

  1. Open File Explorer and navigate to C:\Users\<YourUsername>\Pictures.
  2. Right-click the Screenshots folder and select Properties.
  3. Go to the Location tab.
  4. Click Move..., select your preferred new destination folder, and click Select Folder.
  5. Click Apply, confirm the file transfer prompt by clicking Yes, and then click OK.
