How to Access Windows 11 Advanced Startup Options

The Advanced Startup options menu in Windows 11 is a built-in recovery environment that lets you troubleshoot system issues, access Safe Mode, perform a System Restore, or reset your PC. This guide covers the fastest and most reliable methods to open the Advanced Startup menu, whether your computer boots properly or refuses to load Windows.

Method 1: Via the Settings App

  1. Open Settings by pressing Windows key + I.
  2. Select System from the left sidebar, then click on Recovery.
  3. Locate the Advanced startup section and click the Restart now button next to it.
  4. Confirm your choice by clicking Restart now again in the prompt.

Method 2: Using Shift + Restart

You can trigger Advanced Startup from the Start menu or the lock screen without navigating through settings.

  1. Click the Start button (or access the sign-in screen).
  2. Click the Power icon.
  3. Hold down the Shift key on your keyboard and click Restart.
  4. Continue holding the Shift key until the blue "Choose an option" screen appears.

Method 3: Using Command Prompt or Terminal

  1. Press Windows key + R to open the Run dialog box.
  2. Type cmd and press Enter (or open Windows Terminal).
  3. Type the following command and press Enter: 
    shutdown /r /o /f /t 00
  4. Your computer will immediately restart into the Advanced Startup menu.

Method 4: Using Hard Reboots (If Windows Won't Boot)

If your system crashes or fails to boot into Windows, you can force the system into recovery mode automatically.

  1. Turn on your PC by pressing the power button.
  2. As soon as the manufacturer logo or Windows logo appears, press and hold the power button for 5–10 seconds to force a shutdown.
  3. Repeat this process two more times (three interrupted boots in total).
  4. On the next restart, Windows will display "Preparing Automatic Repair" and boot directly into the Advanced Startup menu.

Method 5: Using Windows 11 Installation Media

  1. Insert a bootable Windows 11 USB drive into your PC.
  2. Restart the computer and boot from the USB drive via your PC's boot menu (usually accessed via F12, F11, or Del).
  3. Select your language preferences and click Next.
  4. Click Repair your computer in the bottom-left corner of the installer window.
