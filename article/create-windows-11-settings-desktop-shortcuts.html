Create Windows 11 Settings Desktop Shortcuts

Windows 11 allows you to streamline your workflow by creating custom desktop shortcuts to specific Settings pages using ms-settings: Uniform Resource Identifier (URI) commands. Instead of manually navigating through the Settings app every time you need to check for updates, manage Bluetooth devices, or adjust display settings, you can launch directly into the required menu with a single click. This guide explains how to set up these shortcuts step-by-step and provides a reference list of the most common Windows 11 Settings URIs.

How to Create a Settings Shortcut

  1. Open the Shortcut Wizard: Right-click an empty space on your desktop, hover over New, and select Shortcut.
  2. Enter the URI Command: In the field labeled Type the location of the item, type or paste the target URI command (for example, ms-settings:windowsupdate).
  3. Name the Shortcut: Click Next, enter a descriptive name for your shortcut (such as "Windows Update"), and click Finish.
  4. Change the Icon (Optional): Right-click your new shortcut, select Properties, switch to the Web Document or Shortcut tab, and click Change Icon to assign an appropriate system icon.

Common Windows 11 Settings URIs

Below are commonly used ms-settings: commands categorized by their section in Windows 11:

System

  • Display Settings: ms-settings:display
  • Sound Settings: ms-settings:sound
  • Notifications: ms-settings:notifications
  • Power & Battery: ms-settings:powersleep
  • Storage: ms-settings:storagesense
  • About (System Information): ms-settings:about

Network & Internet

  • Network Status: ms-settings:network
  • Wi-Fi Settings: ms-settings:network-wifi
  • Ethernet: ms-settings:network-ethernet
  • VPN: ms-settings:network-vpn
  • Data Usage: ms-settings:datausage

Bluetooth & Devices

  • Bluetooth Devices: ms-settings:bluetooth
  • Printers & Scanners: ms-settings:printers
  • Mouse Settings: ms-settings:mousetouchpad

Personalization & Accounts

  • Background: ms-settings:personalization-background
  • Themes: ms-settings:themes
  • Lock Screen: ms-settings:lockscreen
  • Sign-in Options: ms-settings:signinoptions

Apps & System Maintenance

  • Installed Apps: ms-settings:appsfeatures
  • Default Apps: ms-settings:defaultapps
  • Startup Apps: ms-settings:startupapps
  • Windows Update: ms-settings:windowsupdate
  • Windows Security: ms-settings:windowsdefender
