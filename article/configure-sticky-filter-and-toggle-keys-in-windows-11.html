Configure Sticky, Filter, and Toggle Keys in Windows 11

Windows 11 includes built-in accessibility features designed to assist users who have difficulty pressing multiple keys simultaneously, holding down keys, or tracking lock states. This guide explains how to access, enable, and customize Sticky Keys, Filter Keys, and Toggle Keys through the Windows 11 Settings menu, as well as how to trigger them using quick keyboard shortcuts.

Accessing Keyboard Accessibility Settings

To manage any of these keyboard features, you must first navigate to the accessibility settings in Windows 11:

  1. Open the Settings app by pressing Windows Key + I.
  2. Select Accessibility from the left-hand navigation pane.
  3. Scroll down to the Interaction section and click on Keyboard.

How to Configure Sticky Keys

Sticky Keys allows you to press modifier keys—such as Shift, Ctrl, Alt, or the Windows Key—one at a time rather than holding them down simultaneously with other keys.

  • Enable/Disable: Toggle the switch next to Sticky keys to On or Off.
  • Customize Settings: Click the arrow (>) next to the Sticky keys toggle to access advanced options:
    • Keyboard shortcut for Sticky keys: Allows you to turn Sticky Keys on or off by pressing the Shift key five consecutive times.
    • Show the Sticky keys icon on the taskbar: Displays a visual indicator in the system tray when active.
    • Lock shortcut keys when pressed twice in a row: Keeps modifier keys continuously active until pressed a third time.
    • Turn off Sticky keys when two keys are pressed at the same time: Automatically disables the feature if a multi-key press is detected.
    • Play an audio cue: Emits a sound when modifier keys are pressed, locked, or released.

How to Configure Filter Keys

Filter Keys tells Windows to ignore brief or repeated keystrokes, which prevents accidental duplicate inputs caused by unsteady hands or rapid key pressing.

  • Enable/Disable: Toggle the switch next to Filter keys to On or Off.
  • Customize Settings: Click the arrow (>) next to the Filter keys toggle to adjust behavior:
    • Keyboard shortcut for Filter keys: Enables activation by holding down the right Shift key for eight seconds.
    • Show the Filter keys icon on the taskbar: Displays a status icon in the notification area.
    • Beep when keys are pressed or accepted: Plays an audio confirmation for registered inputs.
    • Ignore quick keystrokes (Slow Keys): Sets a delay time requiring keys to be held down for a specific duration before registering.
    • Ignore repeated keystrokes (Bounce Keys): Prevents the system from registering rapid, unintentional repeated presses of the same key.

How to Configure Toggle Keys

Toggle Keys provides an audible alert whenever you turn on or off locking keys, helping you avoid accidental typing in uppercase or using navigation modes unexpectedly.

  • Enable/Disable: Toggle the switch next to Toggle keys to On or Off to immediately hear tones when pressing Caps Lock, Num Lock, or Scroll Lock (a high tone indicates on; a low tone indicates off).
  • Customize Settings: Click the arrow (>) next to Toggle keys to enable the Keyboard shortcut for Toggle keys, which allows you to toggle the service by holding down the Num Lock key for five seconds.
