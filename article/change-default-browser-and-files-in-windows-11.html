Change Default Browser and Files in Windows 11

Managing your default web browser and file associations in Windows 11 allows you to control which applications automatically open specific files, links, and media types. This guide explains how to set your preferred web browser, configure file types individually, use context menus for quick associations, and reset your defaults if necessary, all using the built-in Windows 11 Settings app.

How to Change Your Default Web Browser

Windows 11 makes it simple to switch your default browser from Microsoft Edge to any other installed browser, such as Google Chrome, Mozilla Firefox, or Brave.

  1. Open Settings by pressing Windows Key + I.
  2. Select Apps from the left sidebar, then click on Default apps.
  3. Scroll through the list of installed applications and click on the browser you want to make your default.
  4. Click the Set default button located at the top of the window next to "Make [Browser Name] your default browser."

This action automatically assigns the most common web file types and protocols (such as .htm, .html, HTTP, and HTTPS) to your chosen browser.

How to Manage File Associations by File Type or Protocol

If you want a specific application to handle certain file extensions (like opening .pdf files in Adobe Acrobat instead of a web browser), you can configure associations individually.

  1. Open Settings (Windows Key + I) and navigate to Apps > Default apps.
  2. In the search box labeled Enter a file type or link type, type the extension (for example, .pdf, .mp4, or .docx).
  3. Click on the current default app shown in the search result.
  4. Select your preferred application from the pop-up list.
  5. Click Set default to confirm.

How to Assign Defaults by Application

You can also view and change all file types associated with a single program at once.

  1. Go to Settings > Apps > Default apps.
  2. Scroll down to the Set defaults for applications section and select the application you want to configure.
  3. You will see a complete list of every file extension and link type that the app can handle.
  4. Click any file type to change its associated default program.

How to Change File Associations Using File Explorer

For a quick change without opening the full Settings menu:

  1. Right-click the file you want to open in File Explorer.
  2. Hover over Open with and select Choose another app.
  3. Select the application you want to use.
  4. Click the Always button at the bottom of the dialog box to make this association permanent.

How to Reset Default Apps to Microsoft Recommended Defaults

If your file associations become misconfigured or broken, you can restore system defaults with a single click:

  1. Go to Settings > Apps > Default apps.
  2. Scroll to the very bottom of the page.
  3. Click the Reset button next to Reset all default apps.
  4. Confirm by clicking OK.
