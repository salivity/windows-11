Customize File Explorer Ribbon in Windows 11

Windows 11 replaced the traditional multi-tabbed ribbon interface with a simplified command bar designed for quick actions. This guide explains how to customize the Windows 11 File Explorer command bar, adjust folder options, pin frequently used actions, and restore the classic Windows 10 ribbon interface using system settings and registry modifications.

1. Customizing the Native Windows 11 Command Bar

While the Windows 11 command bar does not allow arbitrary drag-and-drop icon placement, you can control its layout and visible options using native menus:

  • Toggle View Modes and Panes:

    1. Open File Explorer (Win + E).
    2. Click the View menu on the command bar.
    3. Choose your preferred layout (e.g., Details, Large icons, or Compact view).
    4. Hover over Show to toggle the Navigation pane, Preview pane, Details pane, File name extensions, and Hidden items.

  • Access Advanced Options via the Ellipsis Menu:

    1. Click the three dots (...) on the far right of the command bar.
    2. Select Options to open traditional Folder Options.
    3. Under the General tab, set "Open File Explorer to" either Home, This PC, or your personal OneDrive folder.
    4. Under the View tab, customize advanced settings such as hiding empty drives or always showing menus.

2. Customizing the Contextual Actions

The command bar automatically adapts based on the items you select:

  • Standard State: Shows primary actions like New, Cut, Copy, Paste, Rename, Share, and Delete.
  • Item Selected: Unlocks dynamic buttons such as Edit, Rotate left/right (for images), Extract all (for ZIP archives), or Mount (for ISO files).
  • Selection State: Use the See more (...) button on specific selections to access advanced context commands like Map network drive or Cleanup.

3. Restoring the Classic Windows 10 Ribbon in Windows 11

If you require the full multi-tabbed ribbon (Home, Share, View) from Windows 10, you can restore it using the Windows Registry.

Registry Editor Method:

  1. Press Win + R, type regedit, and press Enter.
  2. Navigate to the following path: 
    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked
  3. If the Blocked key does not exist under Shell Extensions, right-click Shell Extensions, select New > Key, and name it Blocked.
  4. Right-click the Blocked folder, select New > String Value.
  5. Set the name of the new string to: 
    {e2bf9676-5f18-4261-9d5e-81703794692b}
  6. Leave the value data blank.
  7. Restart your computer or restart Windows Explorer via Task Manager to apply the classic ribbon interface.

(Note: To revert back to the modern Windows 11 command bar, delete the string value created above and restart your system.)

4. Advanced Customization via Third-Party Tools

For deeper interface personalization not natively supported in Windows 11:

  • StartAllBack: Allows you to switch between the modern command bar, the Windows 10 ribbon, or the classic Windows 7 command bar with full customization of buttons and toolbars.
  • Windhawk: Provides lightweight mods specifically designed to reorder, add, or hide individual buttons on the Windows 11 File Explorer command bar.
