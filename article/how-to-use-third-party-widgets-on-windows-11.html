How to Use Third-Party Widgets on Windows 11

Windows 11 fully supports third-party widgets on the Widgets board, allowing you to customize your dashboard with tools beyond Microsoft’s default offerings. While the feature initially launched with only first-party services like MSN Weather and Microsoft News, system updates expanded the platform to allow independent developers to create custom widgets. This guide explains how third-party widget integration works, where to find compatible widgets, and how to pin them to your board.

How Third-Party Widgets Work in Windows 11

Third-party widgets are bundled directly with their corresponding applications distributed through the Microsoft Store or packaged via the Windows App SDK. When you install a supported app on your PC, its companion widget automatically becomes available within the Windows 11 Widgets interface.

Popular applications offering Windows 11 widgets include:

  • Spotify: Provides quick media playback controls and recommended playlists.
  • Facebook Messenger: Displays recent conversations and quick chat shortcuts.
  • Phone Link: Shows phone battery status, connectivity, and recent messages.
  • Xbox: Displays recently played games and friend activity.

How to Install and Add Third-Party Widgets

To add a third-party widget to your board, follow these steps:

  1. Install the Application: Open the Microsoft Store and search for an app that includes widget support (such as Spotify or Messenger), then install it on your device.
  2. Open the Widgets Board: Click the Widgets icon on the left side of your taskbar or press the Windows key + W keyboard shortcut.
  3. Open the Widget Gallery: Click the "+" (Add widgets) button located in the top-right corner of the Widgets board.
  4. Pin the Widget: In the "Add widgets" menu, scroll through the list to find the newly installed app widget, select it, and click Pin.
  5. Customize the Layout: Once pinned, click the three-dot icon (...) in the upper-right corner of the widget to change its size (Small, Medium, or Large) or customize its individual settings.

Requirements for Third-Party Widgets

To ensure third-party widgets function properly, verify that your operating system is up to date. You must be running Windows 11 version 22H2 or later, and the Windows Web Experience Pack must be updated to the latest version via the Library tab in the Microsoft Store.
