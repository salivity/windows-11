How to Open File Explorer to This PC in Windows 11

By default, Windows 11 opens File Explorer to the "Home" page, displaying recent files, favorites, and pinned folders. If you prefer the traditional view showing your drives, devices, and network locations, you can quickly change the default startup location to "This PC." This guide provides the simple steps required to adjust your File Explorer settings in Windows 11.

Steps to Change File Explorer Default to "This PC"

  1. Open File Explorer Launch File Explorer by clicking its folder icon on the taskbar, or press the keyboard shortcut Windows Key + E.

  2. Open Folder Options In the top menu bar (Command Bar), click the See more icon (represented by three horizontal dots ...), and select Options from the dropdown menu.

  3. Change the Startup Location In the Folder Options window that appears, ensure you are on the General tab. At the very top, locate the dropdown menu labeled Open File Explorer to:.

  4. Select "This PC" Click the dropdown menu and change the selection from Home to This PC.

  5. Save Changes Click Apply in the bottom-right corner, then click OK to close the window.

The next time you open File Explorer, it will automatically load directly into "This PC," giving you immediate access to your local storage drives and connected devices.
