Configure Windows 11 Storage Sense for Low Disk Space

Storage Sense is a built-in Windows 11 maintenance tool that automatically frees up drive space by deleting unnecessary files, such as temporary data and items in your Recycle Bin. Configuring Storage Sense to run automatically when your disk space becomes critically low ensures your system maintains optimal performance and prevents unexpected storage-related crashes without requiring manual cleanup.

How to Enable and Configure Storage Sense

Follow these steps to set Storage Sense to trigger only when your drive is running out of space:

  1. Open Windows Settings: Press Win + I on your keyboard, or click the Start button and select the Settings gear icon.
  2. Access Storage Settings: In the left sidebar, ensure System is selected, then scroll down and click on Storage in the right pane.
  3. Turn On Storage Sense: Locate the Storage management section. Toggle the switch next to Storage Sense to the On position.
  4. Open Configuration Options: Click the arrow next to the Storage Sense toggle (or click directly on the "Storage Sense" text) to open its detailed preferences.
  5. Set the Trigger Condition: Under the Cleanup of temporary files section, find the dropdown menu labeled Run Storage Sense.
  6. Select the Low Disk Space Option: Click the dropdown menu and choose During low free disk space.

Additional Cleanup Preferences

While in the Storage Sense configuration menu, you can fine-tune what gets removed when the tool activates:

  • Keep Windows running smoothly: Check the box next to "Automatic User content cleanup" to ensure temporary system and app files are purged automatically.
  • Recycle Bin Cleanup: Set the threshold (such as 1, 14, 30, or 60 days) for how long deleted files stay in the Recycle Bin before being permanently erased.
  • Downloads Folder Cleanup: Choose how long files can remain untouched in your Downloads folder before Storage Sense deletes them (select Never if you prefer to manage downloads manually).
  • Locally Available Cloud Content: If you use OneDrive, set how long cloud-backed files can stay unused locally before becoming cloud-only placeholders.

Once these settings are applied, Windows 11 will continuously monitor your primary drive and silently run the cleanup process whenever available storage drops to a critical threshold.
