Clear File Explorer History and Cache in Windows 11

Windows 11 automatically tracks your search queries, recently opened files, and frequently visited folders in File Explorer to provide quick access to your data. If you share your computer or want to free up space and maintain your privacy, you can easily erase this stored data. This guide provides step-by-step instructions to clear your File Explorer search history, remove recent file and folder caches, and disable future tracking in Windows 11.

Clear File Explorer History and Recent Files

To delete the cached list of recently opened files and folders from Quick access and the Home page:

  1. Press Windows Key + E to open File Explorer.
  2. Click the three-dot menu icon (See more) on the top toolbar.
  3. Select Options from the drop-down menu to open Folder Options.
  4. In the General tab, locate the Privacy section at the bottom.
  5. Click the Clear button next to Clear File Explorer history.
  6. Click Apply, then click OK.

All cached recent files, frequent folders, and related path entries will immediately disappear from your Home screen.

Clear Recent Search History

To remove past search terms from the File Explorer search box:

Method 1: Delete Directly from the Search Box

  1. Open File Explorer.
  2. Click inside the Search box in the top-right corner.
  3. Hover over an individual past search query in the drop-down list.
  4. Click the X (Delete) icon next to the entry to remove it.

Method 2: Clear Device Search History via Settings

  1. Press Windows Key + I to open Settings.
  2. Click Privacy & security in the left sidebar.
  3. Select Search permissions.
  4. Scroll down to the History section.
  5. Click the Clear device search history button.

Prevent Windows 11 from Saving Recent Files and Searches

If you want to permanently stop File Explorer from storing your recent files and folders:

  1. Open File Explorer, click the three dots, and select Options.
  2. In the General tab under Privacy, uncheck the following boxes:
    • Show recently used files
    • Show frequently used folders
    • Show files from Office.com (if available)
  3. Click Apply and then OK.

To prevent Windows from storing search queries across the operating system, navigate to Settings > Privacy & security > Search permissions and toggle the Search history on this device switch to Off.
