Disable Recommended in Windows 11 Start Menu

Windows 11 displays recently opened files, frequently used applications, and new installations in the "Recommended" section of the Start Menu. While designed for quick access, this feature can clutter your interface and present privacy concerns if you share your screen or device. This guide explains how to disable these recommendations using the Windows Settings app and how to adjust your layout to minimize the space the Recommended section occupies.

How to Turn Off Recommended Files and Apps

You can disable recent apps and files directly through the Windows 11 Settings menu:

  1. Open Settings by pressing Windows Key + I on your keyboard (or click the Start button and select the gear icon).
  2. Click on Personalization in the left-hand sidebar.
  3. Scroll down and select Start.
  4. Toggle the following options to Off:
    • Show recently added apps: Stops newly installed programs from appearing in the Start Menu.
    • Show most used apps: Prevents your frequently opened applications from appearing.
    • Show recently opened items in Start, Jump Lists, and File Explorer: Stops recent files, documents, and folders from appearing in the Recommended section.
    • Show recommendations for tips, shortcuts, new apps, and more: Disables promotional suggestions and tips from Microsoft.

Once these toggles are turned off, the Recommended section will no longer populate with your activity.

How to Minimize the Recommended Area

While Windows 11 does not currently allow you to completely remove the Recommended section header, you can shrink its footprint to make more room for pinned apps:

  1. Navigate to Settings > Personalization > Start.
  2. Under the Layout section at the top of the page, select More pins.
  3. Open the Start Menu to verify the change. The pinned applications area will expand, reducing the Recommended section to a single row.

How to Manually Remove Individual Items

If you want to keep the feature enabled but remove specific files or programs from view:

  1. Open the Start Menu.
  2. Right-click on the specific file or app in the Recommended section.
  3. Select Remove from list.
