Windows 11 File History Backup Frequency and Retention

Windows 11 includes the File History utility to continuously safeguard personal files by saving previous versions to an external storage drive or local network location. This guide provides step-by-step instructions on accessing advanced configuration options in Windows 11 to change how often automatic backups occur and establish retention rules that dictate how long historical file versions are stored.

Access Advanced File History Settings

Windows 11 routes standard backup settings through the modern Settings app, but detailed scheduling and retention rules are managed through the classic Control Panel interface.

  1. Press the Windows Key, type Control Panel, and press Enter.
  2. In the top-right corner of the Control Panel window, set View by to either Large icons or Small icons.
  3. Select File History from the list of available applets.
  4. In the left navigation pane, click Advanced settings.

Configure Backup Frequency

The backup frequency setting dictates how often Windows scans designated folders (such as Documents, Music, Pictures, Videos, and Desktop) and saves copies of modified files.

  1. Under the Versions section in Advanced settings, locate the Save copies of files dropdown menu.
  2. Select your desired frequency interval from the available options:
    • Every 10 minutes
    • Every 15 minutes
    • Every 20 minutes
    • Every 30 minutes
    • Every hour (Default)
    • Every 3 hours
    • Every 6 hours
    • Every 12 hours
    • Daily

Configure Retention Rules

Retention rules manage storage consumption by determining how long previous versions of modified or deleted files remain on the backup drive.

  1. In the same Versions section, locate the Keep saved versions dropdown menu.
  2. Select your preferred retention lifespan:
    • Forever (Default; retains all versions indefinitely until the drive is full)
    • Until space is needed (Automatically deletes the oldest versions only when the backup drive approaches full capacity)
    • 1 month to 2 years (Automatically purges file versions older than the selected timeframe)

Apply and Save Changes

  1. Click the Save changes button at the bottom of the window to apply your new frequency and retention parameters.
  2. To manually trigger an immediate backup using the new rules, return to the main File History page and click Run now.
