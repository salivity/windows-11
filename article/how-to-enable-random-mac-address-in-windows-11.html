How to Enable Random MAC Address in Windows 11

Using random hardware (MAC) addresses in Windows 11 enhances your online privacy by preventing network operators and trackers from monitoring your device's physical location and activity across different Wi-Fi networks. This guide explains how to enable this built-in security feature globally for all Wi-Fi connections or configure it specifically for individual saved networks.

Enable Random MAC Addresses for All Wi-Fi Networks

To apply randomized MAC addresses across all new and existing wireless connections:

  1. Open Settings by pressing Windows Key + I.
  2. Click on Network & internet in the left sidebar.
  3. Select Wi-Fi from the menu on the right.
  4. Locate the Random hardware addresses toggle switch.
  5. Turn the toggle to On.

Once enabled, Windows 11 will use randomized MAC addresses by default whenever your computer scans for networks or connects to a Wi-Fi access point.

Enable Random MAC Addresses for a Specific Wi-Fi Network

If you only want to randomize your address on public or untrusted networks while maintaining a static address on your home network, configure individual settings:

  1. Open Settings (Windows Key + I).
  2. Go to Network & internet > Wi-Fi.
  3. Click on Manage known networks.
  4. Select the specific Wi-Fi network you want to configure.
  5. Find the Random hardware addresses setting.
  6. Use the drop-down menu to select one of the following options:
    • On: Generates a random MAC address for this network.
    • Change daily: Generates a new random MAC address every 24 hours to maximize privacy.
    • Off: Uses your device's original physical hardware address.

Important Considerations

  • Network Disconnection: Changing this setting may temporarily disconnect your Wi-Fi while Windows applies the new hardware address.
  • Network Filters: If a Wi-Fi network relies on MAC address filtering or assigns static IP addresses based on your MAC address, turning this feature on may prevent you from connecting or accessing the internet on that specific network.
