How to Backup Credentials in Windows 11

Backing up stored credentials in Windows 11 ensures you do not lose critical passwords for local network shares, remote desktop connections, and mapped drives. This step-by-step guide explains how to export and protect your Windows credentials using the built-in Credential Manager tool so you can safely restore them later or transfer them to another device.

How to Export and Backup Windows Credentials

Windows 11 includes a native tool within Credential Manager designed specifically for exporting your saved network and system credentials into an encrypted backup file.

  1. Open Credential Manager

    • Press Windows Key + S, type Credential Manager, and press Enter.
    • Alternatively, open the Control Panel, change the View by option to Large icons, and select Credential Manager.

  2. Select Windows Credentials

    • Click on the Windows Credentials tab at the top of the window. (Note: The Web Credentials tab only stores website passwords for legacy browsers and does not support native file export).

  3. Initiate the Backup Process

    • Click the Back up Credentials link located under the main section header.

  4. Select File Destination

    • Click the Browse button to choose where you want to save the backup file.
    • Choose a secure folder (such as an encrypted USB drive), enter a name for the file, and click Save.
    • Click Next to proceed.

  5. Protect the Backup File

    • Press Ctrl + Alt + Delete on your keyboard to switch to the secure desktop prompt.
    • Enter a strong password to encrypt the backup file, confirm the password, and click Next.
    • Click Finish to complete the export process.

The exported .crd file is now saved at your chosen location and protected with the password you defined.

How to Restore Your Backed-Up Credentials

If you reinstall Windows 11 or move to a new computer, you can restore your saved credentials using the same tool:

  1. Open Credential Manager and select Windows Credentials.
  2. Click Restore Credentials.
  3. Click Browse, navigate to your saved .crd file, and select it.
  4. Click Next, press Ctrl + Alt + Delete, and enter the password you set during the export.
  5. Click Finish to add the credentials back to Windows 11.
