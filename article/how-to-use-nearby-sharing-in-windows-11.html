How to Use Nearby Sharing in Windows 11

Nearby Sharing in Windows 11 allows you to wirelessly transfer documents, photos, and web links to other nearby Windows computers using Bluetooth and Wi-Fi. This guide explains how to enable the feature, configure permissions, and send both local files and web pages directly to another PC without needing third-party software or USB drives.

Prerequisites

Before using Nearby Sharing, ensure that both the sending and receiving PCs meet the following criteria:

  • Both devices are running Windows 11 (or Windows 10).
  • Bluetooth and Wi-Fi are turned on for both computers.
  • Both computers are connected to the same private Wi-Fi network (for faster transfers) and are within Bluetooth range of each other.

Step 1: Enable Nearby Sharing on Both PCs

You must turn on the feature on both the sending and receiving computers.

  1. Open Settings by pressing Win + I.
  2. Navigate to System > Nearby sharing.
  3. Select your sharing preference:
    • My devices only: Allows transfers only between PCs signed in with the same Microsoft account.
    • Everyone nearby: Allows your PC to share with and receive files from any nearby Windows device.
  4. (Optional) Click Change next to Save files I receive to if you want to customize the download folder.

Step 2: How to Share Local Files

  1. Open File Explorer and locate the file you want to send (e.g., a photo, video, or document).
  2. Right-click the file and select the Share icon (a rectangle with an arrow pointing out) from the context menu.
  3. In the pop-up window, look for the Nearby sharing section. Windows will search for available devices.
  4. Click on the name of the target PC.
  5. The transfer will begin once the receiving device accepts the request.

Step 3: How to Share Web Links

You can share web links directly from web browsers like Microsoft Edge.

  1. Open Microsoft Edge and go to the webpage you want to share.
  2. Click the Settings and more menu (...) in the top-right corner and select Share (or use the shortcut Ctrl + Shift + S if enabled).
  3. In the sharing menu, choose Windows share options if prompted.
  4. Under the Nearby sharing section, select the target PC to send the link.

Step 4: Accepting Files on the Receiving PC

  1. A notification banner will appear in the bottom-right corner of the target PC's screen.
  2. Click Save & open or Save to accept the file transfer.
  3. If receiving a web link, clicking the notification will automatically open the URL in the default browser.
