How to Install TrueType and OpenType Fonts on Windows 11

Installing new TrueType (.ttf) and OpenType (.otf) fonts on Windows 11 is a straightforward process that allows you to expand your typography choices for design, writing, and system personalization. This guide covers the most efficient methods to install fonts on your PC, including using the context menu, the Windows Settings app, the font viewer, and the Microsoft Store.

Method 1: Install via the Right-Click Context Menu

The quickest way to install a font is directly from File Explorer.

  1. Locate the downloaded font file (.ttf or .otf). If it is in a .zip archive, right-click the archive and select Extract All.
  2. Right-click the font file.
  3. Choose one of the following installation options:
    • Install: Installs the font exclusively for your current user account.
    • Show more options > Install for all users: Installs the font system-wide for every user account on the computer (requires administrator privileges).

Method 2: Drag and Drop in Windows Settings

If you have multiple font files to install at once, the Windows Settings app provides a simple drag-and-drop interface.

  1. Press Windows Key + I to open the Settings menu.
  2. In the left sidebar, click on Personalization.
  3. Select Fonts from the right-hand panel.
  4. Drag your .ttf or .otf files from File Explorer and drop them into the rectangular area labeled Drag and drop to install at the top of the page.
  5. Windows will automatically install the fonts.

Method 3: Install via Font Preview

Previewing a font allows you to inspect its character set before applying it to your system.

  1. Double-click the .ttf or .otf file in File Explorer to open the Windows Font Viewer.
  2. Review the font styles and sample text.
  3. Click the Install button located in the top-left corner of the window.

Method 4: Install Fonts from the Microsoft Store

Windows 11 also allows you to browse and install curated fonts directly through the Microsoft Store.

  1. Open Settings and navigate to Personalization > Fonts.
  2. Click the link that says Get more fonts in Microsoft Store.
  3. Browse the available font packages, select the one you want, and click Free or Get to install it automatically.

How to Manage or Uninstall Installed Fonts

To view, configure, or remove fonts from your system:

  1. Go to Settings > Personalization > Fonts.
  2. Scroll through the list or use the search bar to find the font family.
  3. Click on the font name to view its metadata, change variable font settings, or click the Uninstall button to remove it from Windows 11.
