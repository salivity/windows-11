How to Change Default PDF Reader in Windows 11

By default, Windows 11 opens PDF files using the built-in Microsoft Edge browser. If you prefer a dedicated application like Adobe Acrobat, Foxit Reader, or SumatraPDF, you can easily change this behavior. This guide explains the two most direct methods to set an alternative PDF reader as your system default in Windows 11.

Method 1: Using Windows Settings

  1. Press Windows Key + I to open the Settings app.
  2. Select Apps from the left-hand navigation pane, then click on Default apps.
  3. In the search bar under "Set a default for a file type or link type", type .pdf.
  4. Click on the current default application (usually Microsoft Edge) listed under the .pdf result.
  5. In the pop-up list, select your preferred PDF reader.
  6. Click Set default at the bottom of the window to confirm your choice.

Method 2: Using the File Explorer Context Menu

  1. Open File Explorer and navigate to any .pdf file.
  2. Right-click the PDF file.
  3. Hover your cursor over Open with and select Choose another app.
  4. Select your preferred PDF reader from the list of programs.
  5. Click the Always button at the bottom of the window (or check the box labeled Always use this app to open .pdf files, depending on your specific Windows 11 build).

All PDF files on your computer will now open automatically in your selected application.
