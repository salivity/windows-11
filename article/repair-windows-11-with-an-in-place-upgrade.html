Repair Windows 11 with an In-Place Upgrade

An in-place upgrade allows you to reinstall Windows 11 over your existing operating system without deleting your personal files, settings, or installed applications. This process completely replaces damaged or missing system components with fresh, official files, making it the most reliable method for fixing persistent system errors, corrupted services, or broken core features when built-in tools like SFC and DISM fail.

Prerequisites

  • Ensure your computer is connected to the internet and plugged into a reliable power source.
  • Verify you have at least 20 to 30 GB of free space on your system drive (C:).
  • Temporarily disable third-party antivirus software to prevent conflicts during the installation.

Step 1: Download the Windows 11 ISO

  1. Open a web browser and navigate to the official Microsoft Windows 11 Download page.
  2. Scroll down to the Download Windows 11 Disk Image (ISO) section.
  3. Select Windows 11 (multi-edition ISO) from the dropdown menu and click Download Now.
  4. Choose your preferred product language (matching your current system language) and click Confirm.
  5. Click the 64-bit Download button to save the ISO file to your computer.

Step 2: Mount the ISO File

  1. Open File Explorer and locate the downloaded .iso file.
  2. Right-click the ISO file and select Mount.
  3. If prompted with a security warning, click Open.
  4. File Explorer will open a new virtual DVD drive containing the installation files.

Step 3: Run the Windows Setup

  1. Double-click the setup.exe file located inside the mounted drive.
  2. When the User Account Control (UAC) prompt appears, click Yes to allow the installer to run.
  3. In the Windows 11 Setup window, click Change how Setup downloads updates.
  4. Select Download updates, drivers and optional features (recommended) and click Next.
  5. Read and accept the Microsoft Software License Terms by clicking Accept.

Step 4: Confirm Installation Settings

  1. The installer will check your PC and present the Ready to install screen.
  2. Ensure that the screen explicitly displays:
    • Install Windows 11
    • Keep personal files and apps
  3. If Keep personal files and apps is not displayed, click Change what to keep, select Keep personal files and apps, and click Next.

Step 5: Complete the Repair Installation

  1. Click the Install button to begin the repair process.
  2. The installation will take anywhere from 15 to 45 minutes depending on your system hardware. Your computer will automatically restart several times.
  3. Once the installation finishes, sign in to your Windows account. All core Windows 11 system components will be restored to their default, healthy states while leaving your personal data untouched.
