How to Uninstall or Hide Fonts in Windows 11

Managing the font library in Windows 11 allows you to declutter design software, speed up font selection menus, and free up drive space. While Windows 11 includes numerous pre-installed typefaces for global language support, you can easily hide system fonts you do not use or completely uninstall optional and third-party fonts using built-in settings.

How to Hide System Fonts in Windows 11

Windows protects critical system fonts from deletion to ensure the interface renders correctly. However, you can hide them so they no longer appear in application font menus.

  1. Press Win + R, type control fonts, and press Enter to open the classic Fonts Control Panel.
  2. Select the font family or individual font style you wish to conceal.
  3. Click the Hide button located on the top toolbar.
  4. The font icon will turn translucent, indicating it is now hidden from application font pickers while remaining available for system rendering.

To make hidden fonts visible again, select the translucent font in the same window and click Show on the top toolbar.

How to Uninstall Fonts via Windows Settings

If you have installed third-party fonts or want to remove non-essential fonts, use the Windows 11 Settings app.

  1. Press Win + I to open Settings.
  2. Navigate to Personalization in the left sidebar, then click on Fonts.
  3. Scroll through the list or use the search bar to locate the font you want to remove.
  4. Click on the font to open its details page.
  5. Click the Uninstall button under the font metadata section and confirm when prompted.

Note: If the "Uninstall" button is grayed out, the font is a protected system font and can only be hidden, not uninstalled.

Remove Language-Specific Supplemental Fonts

Windows 11 includes supplemental font packages for non-Latin scripts that can be safely removed via Optional Features.

  1. Open Settings (Win + I).
  2. Go to Apps > Optional features.
  3. Scroll down to the Installed features section.
  4. Look for font packages you do not need (such as Japanese Supplemental Fonts, Korean Supplemental Fonts, or Pan-European Supplemental Fonts).
  5. Click the arrow next to the feature and select Uninstall.
