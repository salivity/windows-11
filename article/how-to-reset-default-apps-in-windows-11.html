How to Reset Default Apps in Windows 11

Resetting application associations in Windows 11 restores all file types, protocols, and standard software configurations back to Microsoft's original factory recommendations. Whether an update altered your preferred software, third-party software caused conflicts, or you simply want a clean slate, Windows 11 includes a built-in feature to reset all defaults globally with just a few clicks.

Steps to Reset App Associations to Microsoft Defaults

  1. Open Windows Settings: Press the Windows Key + I shortcut on your keyboard, or right-click the Start button and select Settings.
  2. Navigate to Apps: In the left sidebar, click on Apps.
  3. Select Default Apps: Click the Default apps tile on the right-side pane.
  4. Locate the Reset Option: Scroll all the way down to the bottom of the page under the Related settings section to find Reset all default apps.
  5. Click Reset: Click the Reset button next to "Reset all default apps to Microsoft recommended defaults."
  6. Confirm the Action: When the confirmation prompt appears asking if you are sure you want to reset all application associations, click OK.

A small checkmark will appear next to the Reset button once the process is complete.

What Happens After the Reset

Executing this reset will immediately:

  • Change your default web browser back to Microsoft Edge.
  • Set the default image viewer to Microsoft Photos.
  • Revert audio and video playback to Windows Media Player or Movies & TV.
  • Reassign common document extensions (like .pdf and .txt) to their default Microsoft-provided applications.

Any third-party software installed on your computer will remain intact, but you will need to manually reassign specific file types if you wish to use alternative programs again in the future.
