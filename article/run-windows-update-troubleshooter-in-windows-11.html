Run Windows Update Troubleshooter in Windows 11

Windows 11 updates can occasionally fail, leaving your system stuck with cryptic error codes that block critical security patches and feature releases. This guide explains how to access and run the built-in Windows Update Troubleshooter in Windows 11 to automatically diagnose issues, repair corrupted update components, and restore normal update operations.

Step-by-Step Guide to Running the Troubleshooter

  1. Open Windows Settings
    Press Windows Key + I on your keyboard to open the Settings app directly. Alternatively, right-click the Start button and select Settings.

  2. Navigate to Troubleshoot Settings
    In the left sidebar, ensure System is selected. Scroll down the right pane and click on Troubleshoot.

  3. Access Additional Troubleshooters
    Click on Other troubleshooters to view the full list of diagnostic tools available on your system.

  4. Run the Windows Update Diagnostic
    Find Windows Update near the top of the list under the "Most frequent" section and click the Run button next to it.

  5. Follow the On-Screen Prompts
    The diagnostic tool will scan your PC for common problems, such as stalled update services, missing registry keys, or corrupt download caches. If issues are identified, the troubleshooter will automatically apply fixes or prompt you to authorize repairs.

  6. Restart Your PC
    Once the troubleshooter completes its scan and applies any necessary fixes, close the window and restart your computer to ensure the changes take effect.

Verify the Fix

After restarting:

  1. Open Settings (Windows Key + I).
  2. Click Windows Update at the bottom of the left sidebar.
  3. Click Check for updates to verify that your pending updates download and install without triggering previous error codes.
