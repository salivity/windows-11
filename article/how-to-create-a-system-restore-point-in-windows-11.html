How to Create a System Restore Point in Windows 11

Creating a system restore point in Windows 11 is an essential troubleshooting safeguard that captures a snapshot of your current operating system files, settings, and registry. This guide provides a step-by-step walkthrough on how to enable system protection and manually generate a restore point so you can easily revert your PC to a working state if an update, driver, or application causes system instability.

Step 1: Open System Properties

  1. Click the Start button or press the Windows Key.
  2. Type Create a restore point into the search bar.
  3. Select the matching result from the list to open the System Properties window directly on the System Protection tab.

Step 2: Enable System Protection (If Disabled)

Before creating a restore point, ensure protection is turned on for your primary system drive:

  1. Under the Protection Settings section, select your main drive (usually Local Disk (C:) (System)).
  2. Check the Protection column. If it says Off, click the Configure button below.
  3. Select the Turn on system protection option.
  4. (Optional) Adjust the Max Usage slider to allocate disk space for restore points (typically 5% to 10% is sufficient).
  5. Click Apply, then click OK.

Step 3: Create the Restore Point

  1. In the System Properties window under the System Protection tab, click the Create... button at the bottom right.
  2. Enter a recognizable description for the restore point (for example, "Before Graphics Driver Update" or the current date). The current date and time are added automatically, but a custom label helps identify why the restore point was made.
  3. Click Create.
  4. Wait a few moments while Windows generates the snapshot.
  5. Once finished, a dialog will appear stating, "The restore point was created successfully."
  6. Click Close, then click OK to exit the System Properties window.
