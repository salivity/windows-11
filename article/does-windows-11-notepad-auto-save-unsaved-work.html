Does Windows 11 Notepad Auto Save Unsaved Work?

Windows 11 Notepad automatically saves and restores unsaved work and open tabs upon restarting the application or the computer. Microsoft introduced an automatic session restore feature in the redesigned Windows 11 Notepad app, allowing users to pick up right where they left off without losing content or being forced to save files before exiting.

How Notepad Session Restore Works

In updated versions of Windows 11, Notepad caches your work continuously in the background. If your computer reboots for updates, unexpectedly crashes, or you intentionally close the application, your unsaved text and open tabs will automatically reappear the next time you launch Notepad.

This feature operates by preserving the application's session state rather than overwriting existing files on your hard drive. As a result, you can work on drafts or untitled documents without constant save prompts interrupting your workflow.

Enabling or Disabling the Auto-Restore Feature

The automatic save and restore functionality is enabled by default, but you can customize it according to your preference:

  1. Open Notepad.
  2. Click the Gear icon (Settings) in the top-right corner.
  3. Locate the section labeled When Notepad starts.
  4. Choose Open content from the previous session to keep automatic restoration active, or select Open a new window if you prefer Notepad to start with a blank document and prompt you to save unsaved changes when closing.

Important Distinction Between Session State and File Saving

While Notepad preserves your text between sessions, it does not permanently create a file on your local storage until you manually save it. If you need to access your document outside of Notepad, share it, or ensure it is backed up to a specific folder or cloud service, you still need to use File > Save (or press Ctrl + S) to assign a file name and directory.
