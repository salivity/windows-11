Manage OneDrive Sync in Windows 11 File Explorer

Managing OneDrive synchronization directly within Windows 11 File Explorer allows you to control local storage, resolve sync issues, and adjust settings without navigating through separate system tray menus. Windows 11 integrates OneDrive controls straight into the File Explorer interface, providing quick access to Files On-Demand options, sync statuses, and configuration menus right from your file viewing window.

Accessing OneDrive Controls in File Explorer

  1. Press Win + E to open File Explorer.
  2. Select your OneDrive folder from the left-hand navigation pane.
  3. Observe the command bar at the top right of the File Explorer window. When you are inside the OneDrive folder, a dedicated OneDrive (cloud) icon appears next to the search bar.
  4. Click this cloud icon to view your current sync status, used storage space, and quick-action shortcuts.

Managing Files On-Demand

You can free up local hard drive space or ensure specific files are always accessible offline using the context menu:

  • Keep files offline: Right-click any file or folder within your OneDrive directory and select Always keep on this device. This downloads the file locally, marked by a solid green circle with a white checkmark.
  • Free up local storage: Right-click a file or folder and select Free up space. The local copy will be removed from your PC while remaining safe in the cloud, marked by a blue cloud icon.

Pausing and Resuming Sync

To temporarily halt synchronization while working in File Explorer:

  1. Click the OneDrive cloud icon located in the top-right toolbar area of File Explorer.
  2. Click the gear icon (Settings) in the dropdown menu.
  3. Hover over Pause syncing and choose your preferred duration (2 hours, 8 hours, or 24 hours).
  4. To resume, click the same menu and select Resume syncing.

Accessing Advanced Settings

If you need to change folder backup selections, account configurations, or network limits:

  1. Click the OneDrive cloud icon in the File Explorer toolbar.
  2. Select the gear icon and click Settings.
  3. The full OneDrive Settings dashboard will open directly on your screen, allowing you to manage account links, notifications, and auto-save preferences.
