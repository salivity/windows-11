Disable Promotional App Suggestions in Windows 11

Windows 11 includes several built-in promotional elements, including recommended apps in the Start menu, suggested content within the Settings app, and periodic tips across the operating system. This guide provides direct, step-by-step instructions to turn off these promotional app suggestions and advertising features across the Windows 11 Start Menu, Settings app, and system notifications for a cleaner, distraction-free desktop experience.

Disable App Suggestions in the Start Menu

  1. Press Windows Key + I to open the Settings app.
  2. Click on Personalization in the left sidebar.
  3. Select Start from the list of options.
  4. Locate the toggle labeled Show recommendations for tips, shortcuts, new apps, and more and switch it to Off.
  5. (Optional) Turn off Show recently added apps if you do not want newly installed application suggestions appearing in the recommended section.

Turn Off Suggested Content in the Settings App

  1. Open Settings (Windows Key + I).
  2. Select Privacy & security from the left navigation menu.
  3. Under the Windows permissions section, click on General.
  4. Toggle the following options to Off:
    • Show me suggested content in the Settings app
    • Let apps show me personalized ads by using my advertising ID
    • Let Windows improve Start and search results by tracking app launches

Disable Tips, Tricks, and System Suggestions

  1. Open Settings and click on System.
  2. Select Notifications.
  3. Scroll to the bottom of the page and click to expand Additional settings.
  4. Uncheck the following three options:
    • Show the Windows welcome experience after updates and when signed in to show what's new and suggested
    • Suggest ways to get the most out of Windows and finish setting up this device
    • Get tips and suggestions when using Windows

Turn Off Promoted Content on the Lock Screen

  1. Open Settings and navigate to Personalization.
  2. Click on Lock screen.
  3. In the Personalize your lock screen drop-down menu, ensure it is set to Picture or Slideshow (Windows Spotlight automatically includes suggestions).
  4. Uncheck the box labeled Get fun facts, tips, tricks, and more on your lock screen.

Disable Ads in File Explorer

  1. Open File Explorer (Windows Key + E).
  2. Click the three-dot menu (...) on the top toolbar and select Options.
  3. In the Folder Options window, click the View tab.
  4. Scroll down the Advanced settings list and uncheck Show sync provider notifications.
  5. Click Apply, then click OK to save the changes.
