How to Clear Windows Update Cache in Windows 11

When Windows 11 updates become stuck, fail to download, or return error codes, corrupted temporary update files are usually the cause. Clearing the Windows Update cache deletes these damaged installation files and forces Windows to download fresh copies from Microsoft's servers. This guide provides quick, step-by-step methods to safely clear the update cache using the Command Prompt, File Explorer, and Disk Cleanup.

Method 1: Clear Cache Using Command Prompt (Recommended)

Using the Command Prompt is the fastest and most reliable way to stop update services, delete cache files, and restart the services.

  1. Press Windows Key + S, type cmd, right-click on Command Prompt, and select Run as administrator.
  2. Stop the core Windows Update services by executing the following commands one by one (press Enter after each): 
    net stop wuauserv
net stop cryptSvc
net stop bits
net stop msiserver
  3. Rename the cache folders to force Windows to create fresh ones: 
    ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
ren C:\Windows\System32\catroot2 catroot2.old
  4. Restart the update services with these commands: 
    net start wuauserv
net start cryptSvc
net start bits
net start msiserver
  5. Close the Command Prompt and restart your computer.

Method 2: Clear Cache Manually via File Explorer

If you prefer using a graphical interface, you can manually stop the services and delete the downloaded cache files.

Step 1: Stop the Windows Update Service

  1. Press Windows Key + R, type services.msc, and press Enter.
  2. Scroll down to locate Windows Update.
  3. Right-click Windows Update and select Stop.
  4. Locate Background Intelligent Transfer Service (BITS), right-click it, and select Stop.

Step 2: Delete Downloaded Files

  1. Press Windows Key + E to open File Explorer.
  2. Navigate to:
    C:\Windows\SoftwareDistribution\Download
  3. Press Ctrl + A to select all files and folders inside the Download folder.
  4. Press Delete (or Shift + Delete) to permanently remove the files. Confirm any administrator prompts.

Step 3: Restart the Services

  1. Return to the Services window.
  2. Right-click Windows Update and select Start.
  3. Right-click Background Intelligent Transfer Service (BITS) and select Start.

Method 3: Use the Disk Cleanup Tool

Windows 11 includes a built-in tool that automatically clears old and redundant update files.

  1. Press Windows Key + S, type Disk Cleanup, and click Run as administrator.
  2. Select your main drive (usually C:) and click OK.
  3. In the list of files to delete, check the box next to Windows Update Cleanup and Temporary files.
  4. Click OK, then click Delete Files to confirm.

Check for Updates Again

After clearing the cache using any of the methods above:

  1. Open Settings by pressing Windows Key + I.
  2. Go to Windows Update.
  3. Click Check for updates.

Windows 11 will now fetch fresh copies of the necessary updates and proceed with the installation without hanging.
