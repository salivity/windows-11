How to Configure Windows 11 Remote Assistance

Windows 11 includes a native Remote Assistance feature (MSRA) that allows a trusted user to take control of or view your PC over the internet or a local network to help troubleshoot technical issues. This guide provides a straightforward walkthrough on how to enable Remote Assistance in System Properties, configure necessary firewall permissions, and generate an invitation to establish a secure remote session.

Step 1: Enable Remote Assistance in System Settings

Remote Assistance is disabled by default on some Windows 11 installations. To enable it:

  1. Press Windows Key + R to open the Run dialog.
  2. Type sysdm.cpl and press Enter to open the System Properties window.
  3. Switch to the Remote tab.
  4. Check the box next to Allow Remote Assistance connections to this computer.
  5. (Optional) Click the Advanced button to configure limits, such as the maximum time an invitation remains open (default is 6 hours) and whether to allow the helper to take full control of the computer.
  6. Click Apply and then OK.

Step 2: Allow Remote Assistance Through Windows Firewall

For the connection to succeed, Windows Defender Firewall must permit Remote Assistance traffic:

  1. Press Windows Key + R, type control firewall.cpl, and press Enter.
  2. In the left sidebar, click Allow an app or feature through Windows Defender Firewall.
  3. Click the Change settings button at the top.
  4. Scroll down and locate Remote Assistance.
  5. Ensure the checkbox next to Remote Assistance is checked, along with the boxes for both Private and Public networks (or Private only if on a trusted home network).
  6. Click OK to save the changes.

Step 3: Create and Send a Remote Assistance Invitation

Once enabled and allowed through the firewall, start a session to invite a helper:

  1. Press Windows Key + R, type msra.exe, and press Enter to open Windows Remote Assistance.
  2. Select Invite someone you trust to help you.
  3. Choose one of the available connection methods:
    • Save this invitation as a file: Generates an .msrcIncident file that you can manually send to the helper via email, chat, or flash drive.
    • Use email to send an invitation: Automatically attaches the file to a draft in your default email client.
    • Use Easy Connect: Establishes a direct peer-to-peer connection if supported by your network configuration.
  4. A window will display a generated 12-character alphanumeric password.
  5. Provide the invitation file and the password to your helper. Keep the password window open on your screen; closing it will cancel the invitation.

Step 4: Connecting as the Helper

To accept the invitation on the helper's machine:

  1. Open msra.exe via the Run dialog.
  2. Select Help someone who has invited you.
  3. Choose Use an invitation file and select the .msrcIncident file provided by the host (or select Use Easy Connect if applicable).
  4. Enter the 12-character password provided by the host.
  5. The host will receive a prompt asking to allow the connection; once the host clicks Yes, the screen sharing session begins. To take keyboard and mouse control, the helper must click the Request control button at the top of the session window, which the host must explicitly accept.
