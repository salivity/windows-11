Custom Commands and Spelling in Windows 11 Voice Access

Windows 11 Voice Access allows users to control their computers and dictate text entirely hands-free. This guide explains how to enhance this assistive tool by creating custom voice commands for repetitive tasks and adding specialized vocabulary to the spelling dictionary. By tailoring these settings to your personal workflow, you can increase system navigation speed and eliminate common dictation errors.

How to Set Up Custom Voice Commands

Custom commands allow you to assign specific actions—such as inserting blocks of text or triggering complex keyboard shortcuts—to a single spoken phrase.

Step 1: Open Voice Access

  1. Press the Windows Key + Ctrl + S or navigate to Settings > Accessibility > Speech and toggle Voice access to On.
  2. Ensure your microphone is active and the Voice Access bar appears at the top of your screen.

Step 2: Open the Command Manager

  1. Click the Settings (gear) icon on the right side of the Voice Access bar.
  2. Select Manage commands from the drop-down menu.
  3. Click the Create new command (or +) button.

Step 3: Configure the Trigger Phrase and Action

  1. Trigger Phrase: In the When I say field, type the exact phrase you want to speak (for example, "insert email signature" or "open project folder").
  2. Action Type: Choose what action Voice Access should execute:
    • Insert text: Enter pre-written text, standard templates, or addresses that you want pasted automatically.
    • Perform shortcut: Assign a keyboard combination (such as Ctrl + Shift + V or Win + D).
    • Open an application/URL: Specify an application executable path or web address.
  3. Click Save to apply the custom command.

How to Configure the Custom Spelling Dictionary

Voice Access relies on a built-in recognition engine, but standard vocabularies may fail to recognize specialized jargon, acronyms, or unique names. Adding these terms to the dictionary prevents repetitive misspellings.

Method 1: Using the "Correct That" Command

  1. Dictate your sentence. If an unusual word is misinterpreted, say "Correct that" or "Correct [word]".
  2. A numbered list of alternative suggestions will appear on screen.
  3. If the correct spelling is not listed, say "Spell that" and spell the word letter-by-letter.
  4. Voice Access will insert the word and automatically save the correct spelling pattern to your local speech profile.

Method 2: Adding Words via Windows Speech Settings

  1. Open Settings by pressing Windows Key + I.
  2. Go to Privacy & security > Inking & typing personalization.
  3. Toggle Custom inking and typing dictionary to On.
  4. To add specific terminology directly to the global Windows dictionary, search for Edit custom dictionary in the Windows search bar or open Notepad, create a word list, and save unusual terms within your user dictionary file located at:
    %AppData%\Microsoft\Spelling\

Managing and Editing Custom Voice Assets

  • To edit or delete commands: Return to the Settings (gear) icon > Manage commands, locate the custom entry, click the three dots (...), and select Edit or Delete.
  • To view standard commands: Say "What can I say?" at any time to open the complete reference guide for built-in navigation and dictation commands.
