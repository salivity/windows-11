How to Set Up Windows 11 Kiosk Mode

Windows 11 Kiosk Mode, powered by Assigned Access, restricts a computer to a single application or a specific set of applications to create a secure, dedicated environment for public use, such as digital signage, interactive displays, or point-of-sale systems. This guide provides a clear, step-by-step walkthrough for configuring, testing, and managing a single-app kiosk setup directly through Windows 11 settings.

Prerequisites for Kiosk Mode

Before beginning configuration, ensure your device meets the following requirements:

  • Edition: Windows 11 Pro, Enterprise, or Education (Kiosk mode is not supported on Windows 11 Home).
  • Account: An administrator account to configure the settings.
  • Application: A Universal Windows Platform (UWP) app or Microsoft Edge. Classic Win32 applications require multi-app kiosk configuration via XML provisioning rather than the standard Settings menu.

Step-by-Step Configuration via Settings

  1. Open Kiosk Settings:

    • Press Windows Key + I to open the Settings menu.
    • Navigate to Accounts on the left-hand sidebar.
    • Scroll down and select Other users.
    • Under the Set up a kiosk section, click Get started.

  2. Create a Dedicated Kiosk Account:

    • Enter a name for the new local kiosk account (e.g., "PublicKiosk" or "GuestAccess").
    • Click Next.

  3. Choose the Kiosk App:

    • Select the application you want to run exclusively on the device from the list of compatible apps.
    • Click Next.

  4. Configure Application Parameters (If Using Microsoft Edge):

    • If you choose Microsoft Edge, select the display mode:
      • As a digital sign or interactive display: Opens a specific URL in full-screen mode with limited browser controls.
      • As a public browser: Runs a multi-tab version of Edge with restricted InPrivate browsing capabilities.
    • Enter the default URL the browser should load upon launch.
    • Specify the idle reset timer to clear browsing data and restart the session after a set period of inactivity.
    • Click Next and then Close.

Running and Testing Kiosk Mode

  1. Restart the device or log out of your administrator account.
  2. On the sign-in screen, select the newly created kiosk account.
  3. The designated application will automatically launch in full screen, disabling access to the desktop, Start menu, File Explorer, and standard system hotkeys.

Exiting Kiosk Mode

To exit the restricted environment:

  1. Press Ctrl + Alt + Delete simultaneously on the keyboard.
  2. Select Sign out or switch to your administrative account.

Removing or Modifying Kiosk Mode

To change the assigned app or disable Kiosk Mode entirely:

  1. Sign in to Windows 11 with your administrator account.
  2. Go to Settings > Accounts > Other users.
  3. Under Set up a kiosk, select Kiosk.
  4. To change the application, click on the current app and choose a replacement.
  5. To disable the kiosk entirely, click Remove kiosk and confirm the deletion of the associated kiosk account and configuration.
