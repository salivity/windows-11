How File History Backs Up Files in Windows 11

File History in Windows 11 is a built-in backup feature that automatically creates point-in-time copies of your personal files to an external storage drive. By monitoring designated folders for changes, it saves updated versions of your documents, photos, and other data on a regular schedule. This allows you to quickly recover previous file states or restore deleted items whenever your external drive is connected.

How File History Functions

File History operates continuously in the background by tracking file modifications. When active, it uses the Windows file system to detect when a file inside a monitored folder has been added, modified, or deleted.

Instead of backing up your entire operating system or applications, File History focuses strictly on user data libraries, including:

  • Documents
  • Pictures
  • Music
  • Videos
  • Desktop folder
  • Saved offline OneDrive files

When a file is modified, File History copies the new version to the designated external drive and appends a date-and-time stamp to the filename. This method preserves a historical timeline of your files without overwriting the original backups.

Storage Structure on the External Drive

When you connect an external hard drive or USB flash drive and enable File History, Windows creates a specific directory structure on the root of the drive:

[Drive Letter]:\FileHistory\[Username]\[ComputerName]\Data\

Inside the Data folder, File History mirrors your PC's original directory tree (such as C\Users\[Username]\Documents). Each file saved will look like:

  • ProjectReport (2023_10_25 14_30_00 UTC).docx
  • ProjectReport (2023_10_25 15_30_00 UTC).docx

This structure ensures that you can manually browse your files using standard File Explorer if necessary, even without using the Windows restore tool.

Backup Schedules and Retention Rules

File History offers customizable backup intervals and retention settings to balance data safety and drive capacity:

  • Backup Frequency: By default, File History saves copies of your files every hour. You can adjust this frequency to range from every 10 minutes to once daily.
  • Keep Saved Versions: You can configure how long Windows retains backup versions. Options range from one month to two years, "Until space is needed," or "Forever" (default). When the external drive fills up, File History can automatically delete the oldest versions to make room for new ones.

If the external drive is disconnected, File History continues tracking changes and temporarily caches version data on your local hard drive. Once the external drive is reconnected, File History transfers the cached versions and updates the external storage automatically.

Restoring Files with File History

Restoring files is integrated directly into Windows:

  1. Open Control Panel and navigate to File History (or search for "Restore your files with File History" in the taskbar).
  2. Browse through the backup snapshots using the forward and back navigation arrows at the bottom of the window to find the desired date and time.
  3. Select the file, folder, or specific version you want to recover.
  4. Click the green Restore button to return the file to its original location, or right-click to restore it to a different path.
