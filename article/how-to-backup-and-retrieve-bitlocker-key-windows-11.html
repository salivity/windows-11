How to Backup and Retrieve BitLocker Key Windows 11

This guide explains how to back up and retrieve your BitLocker recovery key in Windows 11. BitLocker drive encryption safeguards your data, but accessing your system during hardware changes or startup errors requires a 48-digit recovery key. Following the steps below ensures you have a secure backup in place and know exactly where to find your key if your drive becomes locked.

How to Back Up Your BitLocker Recovery Key

You can create a backup of your BitLocker recovery key at any time through the Windows 11 Control Panel.

  1. Open the Start Menu, search for Control Panel, and open it.
  2. Click on System and Security, then select BitLocker Drive Encryption.
  3. Locate the drive you want to manage and click Back up your recovery key.
  4. Choose one or more of the following backup destinations:
    • Save to your Microsoft account: Automatically syncs the key to your cloud-linked Microsoft profile.
    • Save to a USB flash drive: Stores the key directly on an external USB storage device.
    • Save to a file: Exports the key as a text file (must be saved to a non-encrypted external drive or network location).
    • Print the recovery key: Produces a physical hard copy of the key.
  5. Follow the on-screen prompts to complete the process and click Finish.

How to Retrieve Your BitLocker Recovery Key

If Windows prompts you for your recovery key at startup, use one of the methods below based on how your key was originally backed up.

1. From Your Microsoft Account Online

If your PC is linked to a personal Microsoft account:

  1. On another device, go to https://account.microsoft.com/devices/recoverykey.
  2. Sign in with the same Microsoft account used on your locked PC.
  3. Locate your device name to view the 48-digit BitLocker recovery key.

2. From a Work or School Account (Azure AD / Entra ID)

If your device is registered with an organization or school:

  1. Visit https://myaccount.microsoft.com.
  2. Sign in with your organization credentials.
  3. Select Devices, find your computer, and click View BitLocker Keys.

3. From a Saved File, Printout, or USB Drive

  • Printout: Check physical document folders or safe storage where you keep important technical records.
  • Text File: Insert the backup flash drive into another working computer and open the saved .txt file containing the key.
  • USB Key File: If the key was saved as a .bek file on a USB drive, plug that drive directly into your locked PC during the BitLocker prompt to unlock it automatically.

4. Using Command Prompt (If Already Logged In)

If you currently have access to Windows and want to view your key:

  1. Right-click the Start button and select Terminal (Admin) or Command Prompt (Admin).
  2. Type the following command and press Enter: 
    manage-bde -protectors -get C:
  3. Locate the 48-digit numerical password listed under the Password section.
