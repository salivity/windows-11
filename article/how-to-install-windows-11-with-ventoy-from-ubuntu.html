How to Install Windows 11 with Ventoy from Ubuntu?

Installing Windows 11 on unsupported hardware without linking a Microsoft account can be accomplished smoothly using a bootable USB created in Ubuntu. This walkthrough covers downloading the required files, installing Ventoy on your flash drive, configuring Ventoy to automatically bypass TPM, Secure Boot, and online account checks, and completing a clean operating system installation.

Prerequisites

Before starting, ensure you have:

  • An 8 GB or larger USB flash drive (all existing data will be wiped).
  • The official Windows 11 ISO downloaded from Microsoft's website.
  • The latest Ventoy Linux package (ventoy-x.x.xx-linux.tar.gz) downloaded from the official Ventoy GitHub releases page.
  • Administrative (sudo) access on your Ubuntu system.

Installing Ventoy on the USB Drive in Ubuntu

  1. Insert your USB drive into your Ubuntu machine.
  2. Open the Terminal (Ctrl + Alt + T) and run lsblk to identify your USB drive's device path (for example, /dev/sdb). Make sure you do not select your internal OS disk.
  3. Navigate to your downloads directory and extract the Ventoy tarball:
tar -xvf ventoy-*-linux.tar.gz
cd ventoy-*/
  1. Install Ventoy onto the drive using the command-line script, replacing /dev/sdX with your actual drive path:
sudo ./Ventoy2Disk.sh -i /dev/sdX

Confirm the prompts to partition and format the drive.

Alternatively, you can launch the graphical interface by running sudo ./VentoyWeb.sh, navigating to [http://127.0.0.1:24609](http://127.0.0.1:24609) in your web browser, and clicking the install button.

Configuring Automated Bypasses for Hardware and Accounts

Ventoy includes native support to inject registry bypasses into the Windows 11 installer dynamically at boot. This avoids manual registry editing during setup.

  1. Open your file manager and mount the newly created primary partition of your USB drive (labeled Ventoy).
  2. Inside the root of the Ventoy partition, create a new folder named ventoy (lowercase).
  3. Inside the ventoy folder, create a new text file named ventoy.json.
  4. Open ventoy.json in a text editor, paste the following configuration, and save it:
{
  "control": [
    { "VTOY_WIN11_BYPASS_CHECK": "1" },
    { "VTOY_WIN11_BYPASS_NRO": "1" }
  ]
}
  • VTOY_WIN11_BYPASS_CHECK: Automatically instructs the installer to ignore restrictions regarding TPM 2.0, Secure Boot, CPU family, and RAM minimums.
  • VTOY_WIN11_BYPASS_NRO: Disables the mandatory internet connection and Microsoft account prompt during setup, restoring the offline account option.

Copying the Windows 11 ISO

  1. Copy the Windows 11 .iso file directly onto the root of the Ventoy USB partition.
  2. Ensure the copy process finishes completely by running the following command in the Terminal before removing the drive:
sync
  1. Safely unmount and unplug the USB drive.

Booting and Installing Windows 11

  1. Insert the USB drive into the target PC and enter the boot menu (commonly triggered by pressing F12, F11, F8, or Del during startup).
  2. Select the USB drive from the boot options.
  3. In the Ventoy boot menu, select the Windows 11 ISO and choose "Boot in normal mode."
  4. Proceed through the initial setup screens. Ventoy's injected keys will skip the hardware compatibility verification screen automatically.
  5. When prompted to select an installation type, choose "Custom: Install Windows only (advanced)" to partition your drive and begin copying files.

Setting Up an Offline Local Account

Once the setup reaches the Out-of-Box Experience (OOBE) regional and network screens:

  1. When prompted to connect to a Wi-Fi or Ethernet network, click the option labeled "I don't have internet."
  2. If network setup still appears, press Shift + F10 on your keyboard to open the Command Prompt, type oobe\bypassnro, and press Enter. The machine will reboot back to setup with network enforcement disabled.
  3. Disconnect any physical Ethernet cable to prevent Windows from trying to detect an active connection.
  4. On the next screen, select "Continue with limited setup."
  5. Enter your preferred username and password to create a standard offline local account, then proceed through privacy toggles to finish entering the desktop.
