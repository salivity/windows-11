How to Sync Settings and Passwords on Windows 11

Syncing your personal settings, theme colors, and browser passwords across multiple Windows 11 devices creates a seamless, personalized computing experience. By linking a Microsoft account to your PCs, configuring Windows Backup, and turning on browser synchronization, your desktop preferences, custom accents, and saved login credentials will automatically transfer whenever you switch between machines.

Step 1: Sign in with a Microsoft Account

Windows 11 requires a Microsoft account to synchronize system preferences across devices.

  1. Open Settings (press Windows Key + I).
  2. Go to Accounts in the left sidebar.
  3. Check the top of the window. If you are signed in with a local account, select Sign in with a Microsoft account instead and follow the on-screen prompts. Ensure you use the exact same account on all PCs you want to keep in sync.

Step 2: Enable Windows Backup and Preferences Sync

Once signed in, enable the Windows Backup features that handle system preferences, theme choices, and personalization.

  1. In Settings, navigate to Accounts > Windows backup.
  2. Expand the Remember my preferences section.
  3. Toggle the master switch to On.
  4. Check the boxes for:
    • Passwords: Syncs Wi-Fi profiles and credential manager data.
    • Language preferences: Syncs keyboards and display languages.
    • Other Windows settings: Syncs personalization details like theme colors, taskbar preferences, and mouse settings.

Step 3: Sync Theme Colors and Desktop Personalization

Personalization sync relies on OneDrive alongside Windows Backup.

  1. Ensure the OneDrive desktop app is running and signed into the same Microsoft account.
  2. In Settings > Personalization, choose your preferred background, colors, and dark/light mode settings.
  3. These choices are bundled into your synced profile and will automatically apply to any secondary Windows 11 PC signed into the same account once connected to the internet.

Step 4: Sync Browser Passwords (Microsoft Edge)

To sync saved website passwords, bookmarks, and form-fill data across your devices using the default browser:

  1. Open Microsoft Edge.
  2. Click your profile icon in the top-right corner and select Sign in to sync data (or click Manage profile settings if already signed in).
  3. Select Sync.
  4. Turn on the toggles for Passwords, Favorites, and Autofill settings.

Note: If you use a third-party browser such as Google Chrome or Mozilla Firefox, open that browser's settings menu, sign in to your respective Google or Firefox account, and enable synchronization for passwords and autofill data on each PC.
