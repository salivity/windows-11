How to Share a USB Printer on Windows 11

Sharing a locally connected USB printer on a Windows 11 local area network (LAN) allows multiple computers to print through a single host machine. This guide provides a straightforward walkthrough on how to configure your network settings, enable printer sharing on the primary Windows 11 PC, and connect secondary client computers across the same local network.

Step 1: Configure Network Sharing on the Host PC

Before sharing the printer, ensure your network profile allows local device communication:

  1. Open Settings (press Win + I) and select Network & internet.
  2. Click on your active network connection (Wi-Fi or Ethernet) and ensure the network profile type is set to Private network.
  3. Return to Network & internet and click Advanced network settings.
  4. Select Advanced sharing settings.
  5. Under Private networks, turn the toggle to On for File and printer sharing.
  6. (Optional) Under All networks, adjust Password-protected sharing based on your security preference. If turned off, users can connect without entering host credentials.

Step 2: Share the USB Printer

Once sharing is enabled on the network, set the specific printer to shareable:

  1. Open Settings and navigate to Bluetooth & devices > Printers & scanners.
  2. Click on your connected USB printer from the list.
  3. Select Printer properties.
  4. In the pop-up window, click the Sharing tab.
  5. Check the box labeled Share this printer.
  6. Enter a recognizable Share name (avoid spaces and special characters for better compatibility).
  7. Click Apply, then OK.

Step 3: Find the Host PC Name

The client PCs will need the host computer's name to locate the shared printer:

  1. Open Settings > System.
  2. Locate your PC name near the top of the window (e.g., DESKTOP-HOSTPC). Note this down.

Step 4: Connect to the Printer from Client PCs

On any other Windows PC connected to the same LAN:

  1. Open Settings and go to Bluetooth & devices > Printers & scanners.
  2. Click the Add device button.
  3. Wait a few seconds, then click the Add manually link next to The printer that I want isn't listed.
  4. Select Select a shared printer by name.
  5. Type the path to the printer in the following format:
    \\HostPCName\PrinterShareName
    (Example: \\DESKTOP-HOSTPC\CanonUSB)
  6. Click Next. Windows will install the necessary drivers.
  7. Click Finish to complete the setup.

Note: The host PC must remain powered on and awake for client computers to print.
