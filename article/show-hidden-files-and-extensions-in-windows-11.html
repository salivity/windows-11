Show Hidden Files and Extensions in Windows 11

By default, Windows 11 conceals specific file name extensions and system files to maintain a cleaner interface and prevent accidental modifications. This guide explains how to quickly configure File Explorer to display both hidden items and file extensions using the modern command bar or the classic Folder Options menu.

Method 1: Using the File Explorer View Menu

The fastest way to toggle these settings is directly from the File Explorer toolbar.

  1. Press Windows Key + E to open File Explorer.
  2. Click the View dropdown menu on the top command bar.
  3. Hover your cursor over the Show submenu at the bottom of the list.
  4. Click File name extensions to add a checkmark and make extensions visible.
  5. Repeat the process and click Hidden items to reveal hidden files and folders.

Method 2: Using Folder Options

For advanced configuration, including the option to display protected operating system files, use the Folder Options dialogue.

  1. Open File Explorer.
  2. Click the See more icon (the three horizontal dots ...) in the top menu bar.
  3. Select Options to open the Folder Options window.
  4. Switch to the View tab.
  5. In the Advanced settings list:
    • Under Hidden files and folders, select Show hidden files, folders, and drives.
    • Uncheck the box labeled Hide extensions for known file types.
    • (Optional) Uncheck Hide protected operating system files (Recommended) if you need to access core Windows system files.
  6. Click Apply, then click OK to save the changes.
