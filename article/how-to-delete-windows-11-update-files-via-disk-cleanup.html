How to Delete Windows 11 Update Files via Disk Cleanup

Over time, Windows 11 accumulates residual update files, temporary installation packages, and cached components that can take up gigabytes of valuable storage space. While these files allow you to roll back updates if an error occurs, they are no longer necessary once your system is running stably. This guide explains how to safely remove these leftover Windows Update installation files using the native Disk Cleanup tool.

Step 1: Open Disk Cleanup as Administrator

  1. Press the Windows Key + S to open the search bar.
  2. Type Disk Cleanup into the search box.
  3. Right-click on the Disk Cleanup app in the results and select Run as administrator (or click the Clean up system files button once the app opens).

Step 2: Select the System Drive

  1. If prompted, select the drive where Windows 11 is installed (usually the C: drive) from the drop-down menu.
  2. Click OK. The tool will scan the drive to calculate how much space you can free up.

Step 3: Select Windows Update Files for Deletion

In the Disk Cleanup window, scroll through the list labeled Files to delete and check the boxes for the update-related items:

  • Windows Update Cleanup: Deletes copies of installed updates that are no longer needed.
  • Delivery Optimization Files: Deletes cached update files downloaded from other local computers or Microsoft servers.
  • Previous Windows installation(s) (if available): Contains files from an older version of Windows (the Windows.old folder).
  • Temporary Windows installation files: Removes installation files used during the upgrade process.

Step 4: Run the Cleanup Process

  1. After selecting the desired categories, click OK at the bottom of the window.
  2. A confirmation prompt will appear asking if you are sure you want to permanently delete these files. Click Delete Files.
  3. Wait for the process to complete. Disk Cleanup will remove the residual files and reclaim your disk space.

Note: Removing "Windows Update Cleanup" files means you will not be able to uninstall the current Windows updates or roll back to a previous build.
