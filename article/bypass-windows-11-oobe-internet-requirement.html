Bypass Windows 11 OOBE Internet Requirement

Microsoft requires an active internet connection and a Microsoft account to complete the initial setup on Windows 11 Home and Pro editions. However, you can bypass this requirement during the Out-of-Box Experience (OOBE) using a simple command-line workaround. This guide explains how to skip the network requirement and set up Windows 11 with an offline, local account.

Why Bypass the Internet Requirement?

Skipping the network setup during the OOBE is useful if:

  • You want to set up an offline local account instead of linking a Microsoft account.
  • Your device lacks working Wi-Fi or Ethernet drivers during the fresh installation.
  • You do not have access to an active internet connection.

Step-by-Step Guide to Bypass the Network Requirement

Step 1: Reach the Network Setup Screen

Turn on your PC and proceed through the initial region and keyboard layout selection screens until you reach the screen that says "Let's connect you to a network."

Step 2: Open the Command Prompt

  1. On your keyboard, press Shift + F10. (On some laptops, you may need to press Fn + Shift + F10).
  2. A Command Prompt window will appear over the setup screen.

Step 3: Execute the Bypass Command

  1. Click into the Command Prompt window.
  2. Type the following command exactly as shown: 
    OOBE\BYPASSNRO
  3. Press Enter.

Step 4: Complete the Offline Setup

  1. Your computer will automatically reboot and return to the beginning of the Windows 11 setup screen.
  2. Select your region and keyboard layout again.
  3. When you reach the "Let's connect you to a network" screen, a new option will appear: "I don't have internet." Click it.
  4. On the following screen, click "Continue with limited setup."
  5. Enter your desired username, set an optional password, and finish setting up your local Windows 11 profile.
