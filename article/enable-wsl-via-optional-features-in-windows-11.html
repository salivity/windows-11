Enable WSL via Optional Features in Windows 11

The Windows Subsystem for Linux (WSL) allows developers and power users to run a GNU/Linux environment directly on Windows 11 without the overhead of a traditional virtual machine or dual-boot setup. This guide provides a straightforward, step-by-step walkthrough for enabling WSL using the built-in Optional Features graphical interface in Windows 11.

Step 1: Open the Windows Features Menu

  1. Press the Windows Key + R to open the Run dialog box.
  2. Type optionalfeatures and press Enter, or search for Turn Windows features on or off in the Start menu search bar and select the top result.

Step 2: Enable WSL and Virtual Machine Platform

  1. In the Windows Features pop-up window, scroll down the list of available components.
  2. Locate and check the box next to Windows Subsystem for Linux.
  3. To ensure compatibility with WSL 2, also locate and check the box next to Virtual Machine Platform.
  4. Click the OK button at the bottom of the window.

Step 3: Restart Your Computer

  1. Windows will apply the necessary system changes and search for required files.
  2. When prompted, click Restart now to complete the feature installation. A system reboot is mandatory for the changes to take effect.

Step 4: Install a Linux Distribution

Once your computer restarts, the core WSL feature is active. To begin using Linux:

  1. Open the Microsoft Store from the Start menu.
  2. Search for your preferred Linux distribution (such as Ubuntu, Debian, or openSUSE).
  3. Click Get or Install.
  4. Once installed, launch the distribution from the Start menu to complete the initial user account configuration.
