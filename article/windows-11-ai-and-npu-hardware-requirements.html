Windows 11 AI and NPU Hardware Requirements

Microsoft has introduced a dedicated tier of hardware specifications, branded as Copilot+ PCs, designed to power advanced on-device artificial intelligence in Windows 11. This article outlines the exact hardware standards, focusing on the Neural Processing Unit (NPU) performance, memory, storage, and compatible processor platforms required to execute local AI models without cloud dependence.

Core NPU Requirements: 40+ TOPS

The defining requirement for running advanced on-device AI features in Windows 11 is a high-performance Neural Processing Unit (NPU).

  • Performance Baseline: The NPU must achieve at least 40 TOPS (Trillions of Operations Per Second).
  • Purpose: Local NPUs offload intensive AI calculation workloads from the CPU and GPU, ensuring features run continuously in real time with minimal battery drain and reduced system latency.

Standard NPUs found in older generation chips that offer lower compute performance (such as 10–16 TOPS) can handle basic tasks like background blur in camera feeds, but do not meet the criteria for full on-device Windows 11 AI experiences.

Minimum System Specifications

Beyond the NPU, Windows 11 requires robust supporting hardware to ensure smooth model execution:

  • RAM: Minimum 16 GB DDR5 / LPDDR5. Local AI models require significant dedicated system memory to remain resident and responsive.
  • Storage: Minimum 256 GB SSD / NVMe. Fast solid-state storage is necessary to load models quickly into memory.
  • Display: Standard Windows 11 display requirements (720p or higher, 8-bit per color channel).

Compatible Processor Platforms

To meet the 40+ TOPS threshold alongside the necessary memory bandwidth, systems must use specific processor architectures:

  • Qualcomm: Snapdragon X Elite and Snapdragon X Plus (up to 45 TOPS NPU).
  • AMD: Ryzen AI 300 series processors (up to 50 TOPS NPU).
  • Intel: Core Ultra 200V series processors, codenamed Lunar Lake (up to 48 TOPS NPU).

Windows 11 Features Dependent on This Hardware

Meeting these hardware standards unlocks several native on-device capabilities:

  • Windows Recall: Organizes photographic memory of system activity using local multimodal models.
  • Live Captions with Real-Time Translation: Translates live audio from over 40 languages into English instantly on-device.
  • Cocreator in Paint: Generates and refines artwork in real time based on text prompts and hand-drawn sketches.
  • Advanced Windows Studio Effects: Provides real-time lighting adjustments, creative filters, voice focus, and eye contact correction.
  • Restyle Image and Image Creator: Generates local style transfers and photo enhancements within the native Photos app.
  • Automatic Super Resolution (Auto SR): Uses local AI to upscale frame rates and fidelity in games without burdening the primary GPU.
