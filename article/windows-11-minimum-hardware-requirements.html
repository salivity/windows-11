Windows 11 Minimum Hardware Requirements

Upgrading to or installing Windows 11 requires a PC that meets Microsoft's official baseline system specifications. Compared to previous versions, Windows 11 introduces stricter security and architecture standards—most notably requiring a compatible 64-bit processor, UEFI Secure Boot, and a Trusted Platform Module (TPM) 2.0 chip. Below is the straightforward list of minimum hardware requirements needed to successfully run the operating system.

Processor

  • Speed & Cores: 1 gigahertz (GHz) or faster with 2 or more cores.
  • Architecture: Compatible 64-bit processor or System on a Chip (SoC).
  • Supported Models: Generally Intel 8th Generation and newer, AMD Ryzen 2000 series and newer, or select Qualcomm Snapdragon processors.

Memory (RAM)

  • Minimum: 4 gigabytes (GB) of RAM.

Storage

  • Minimum: 64 GB or larger storage device (SSD or HDD). Additional space may be required over time for updates and specific features.

System Firmware

  • Type: UEFI (Unified Extensible Firmware Interface).
  • Capability: Secure Boot capable.

Security

  • TPM: Trusted Platform Module (TPM) version 2.0 enabled on the motherboard or firmware level (Intel PTT / AMD fTPM).

Graphics Card

  • Compatibility: DirectX 12 or later compatible.
  • Driver: WDDM 2.0 (Windows Display Driver Model) driver.

Display

  • Resolution: High Definition (720p).
  • Size & Color: Greater than 9 inches diagonally, with support for 8 bits per color channel.

Internet Connection and Microsoft Account

  • Initial Setup: Windows 11 Home and Pro editions require an active internet connection and a Microsoft account to complete initial device setup (Out of Box Experience).
