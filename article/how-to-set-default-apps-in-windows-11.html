How to Set Default Apps in Windows 11

Windows 11 allows you to customize your operating system by choosing which programs automatically open specific files and protocols. This guide provides a straightforward walkthrough for configuring your default applications for web browsing, email, music playback, video streaming, and photo viewing using the centralized Windows 11 Settings menu.

Access the Default Apps Settings

To begin configuring your applications:

  1. Open the Start Menu and click the Settings gear icon (or press Windows Key + I).
  2. In the left sidebar, select Apps.
  3. In the right pane, click on Default apps.

Setting a Default Web Browser

  1. In the search box under "Set defaults for applications," type the name of your preferred browser (e.g., Google Chrome, Mozilla Firefox, Brave).
  2. Click on the browser in the search results.
  3. At the top of the page, click the Set default button next to "Make [Browser Name] your default browser." This automatically assigns common web formats like HTTP, HTTPS, .htm, and .html to that browser.

Setting a Default Email Client

  1. In the Default apps search bar, type your preferred email app (such as Outlook, Thunderbird, or Mail).
  2. Click on the application from the list.
  3. Locate the MAILTO protocol entry.
  4. Click on the current default app next to MAILTO and select your preferred email application from the popup menu, then click Set default.

Setting a Default Music Player

  1. Search for your preferred audio player (such as VLC media player, Spotify, or Media Player) in the Default apps search bar and select it.
  2. Review the list of audio file extensions (e.g., .mp3, .wav, .flac, .aac, .m4a).
  3. Click on any file extension you want to reassign, select your preferred player from the list, and confirm your choice.

Setting a Default Video Player

  1. Search for your chosen media player (e.g., VLC media player, Films & TV, or MPC-HC) in the Default apps menu and click on it.
  2. Scroll through the supported video formats (e.g., .mp4, .mkv, .avi, .mov, .wmv).
  3. Click each extension you want to update, choose your media player, and click Set default.

Setting a Default Photo Viewer

  1. In the Default apps search bar, enter the name of your preferred image software (such as Photos, IrfanView, or Adobe Photoshop) and click it.
  2. Look through common image extensions including .jpg, .jpeg, .png, .gif, and .bmp.
  3. Click the extension, choose your preferred photo viewer from the list, and click Set default.

Alternative: Set Defaults by File Type

If you have a specific file format not covered by application search:

  1. Scroll to the bottom of the main Default apps page.
  2. Under "Related settings," click Choose defaults by file type.
  3. Type the specific file extension (e.g., .pdf or .mkv) into the search bar at the top.
  4. Click the app currently associated with that extension and pick your preferred replacement.
