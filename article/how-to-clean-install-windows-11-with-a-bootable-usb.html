How to Clean Install Windows 11 with a Bootable USB

A clean installation of Windows 11 removes all existing files, settings, and bloatware from your system, providing a fresh, stable operating environment. This guide outlines the entire process, from creating a bootable USB installation drive with at least 8 GB of storage to configuring your computer’s boot menu, wiping the target drive, and completing the initial Windows setup.

Prerequisites Before You Begin

  1. Backup Your Data: A clean install completely erases the target drive. Back up all essential personal files to an external drive or cloud storage.
  2. USB Flash Drive: A blank USB drive with at least 8 GB of capacity (all existing data on the USB will be deleted).
  3. Product Key: Ensure you have your Windows 10/11 digital license tied to your Microsoft account or a valid 25-character product key.

Step 1: Create the Bootable Windows 11 USB Drive

  1. Insert your USB drive into a working PC.
  2. Go to the official Microsoft software download page and locate Create Windows 11 Installation Media.
  3. Download and launch the Media Creation Tool.
  4. Accept the license terms and select your preferred language and edition.
  5. Choose USB flash drive as the media type.
  6. Select your USB drive from the list and click Next.
  7. Wait for the tool to download Windows 11 and write the installation files to the USB drive. Click Finish when complete.

Step 2: Boot the Target PC from the USB Drive

  1. Insert the newly created bootable USB drive into the PC you want to format.
  2. Power on or restart the PC.
  3. Immediately press the dedicated Boot Menu key repeatedly as the device starts up. Common keys include:
    • F12 (Dell, Lenovo)
    • F9 (HP)
    • F8 or F11 (ASUS, MSI, ASRock)
    • Esc or Delete (general motherboards/laptops)
  4. In the boot menu, select your USB drive (often labeled as UEFI: [USB Brand Name]) and press Enter.

Step 3: Configure Windows 11 Setup and Partitions

  1. When the Windows Setup screen loads, select your language, time format, and keyboard input method, then click Next.
  2. Click Install now.
  3. If prompted for a product key:
    • Enter your key, or click "I don't have a product key" if Windows 11 was previously activated on this computer.
  4. Select the edition of Windows 11 corresponding to your license (e.g., Home or Pro) and accept the software license terms.
  5. On the "Which type of installation do you want?" screen, select Custom: Install Windows only (advanced).
  6. Manage your drives:
    • Select each partition on the primary drive where Windows is currently installed and click Delete.
    • Continue deleting partitions until your primary drive displays only Unallocated Space.
  7. Select the Unallocated Space and click Next. Windows will automatically create the required partitions and begin copying files.

Step 4: Complete the Out-of-Box Experience (OOBE)

  1. Once the file transfer completes, the system will restart automatically. Remove the USB drive during the restart to prevent the installer from launching again.
  2. Follow the on-screen prompts to select your country/region and keyboard layout.
  3. Name your device and connect to a Wi-Fi or Ethernet network.
  4. Sign in with your Microsoft account (or set up an offline account if using Windows 11 Pro).
  5. Choose your privacy settings according to your preference and click Accept.
  6. Allow Windows to finish the setup process. Once the desktop appears, navigate to Settings > Windows Update to check for and install all necessary device drivers and system patches.
