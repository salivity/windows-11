Find Unicode Symbols with Windows 11 Character Map

The Windows 11 Character Map is a built-in utility that allows you to locate, view, and copy thousands of special characters, foreign letters, and uncommon Unicode symbols that do not appear on standard keyboards. This guide provides a direct walkthrough on how to launch the Character Map, filter characters using Unicode subranges, search for specific glyphs, and copy them directly into your documents.

How to Open the Character Map

  1. Press the Windows Key + R to open the Run dialog box.
  2. Type charmap and press Enter (or search for "Character Map" in the Windows Search bar).

Configuring Unicode and Advanced View

To access the full library of Unicode symbols, you must enable the advanced sorting options:

  1. Check the box labeled Advanced view at the bottom left of the window.
  2. In the Font dropdown menu at the top, select a versatile font such as Segoe UI, Arial, or Lucida Sans Unicode, as these fonts contain extensive Unicode character sets.
  3. Ensure the Character set dropdown menu is set to Unicode.

Finding Uncommon Symbols by Category

Using Unicode subranges is the most efficient way to browse specialized groups of characters (such as arrows, mathematical operators, or currency symbols):

  1. In the Group by dropdown menu, select Unicode Subrange. A small secondary window will appear to the right.
  2. Click through the categories in this window to filter the grid. Common categories for rare symbols include:
    • Mathematical Operators (e.g., \(\approx\), \(\neq\), \(\infty\))
    • Currency Symbols (e.g., €, ¥, ₿)
    • Arrows (e.g., ⇄, ⇗, ➔)
    • Dingbats and Geometric Shapes (e.g., ◼, ▲, ❖)
    • Box Drawing and Block Elements

Searching for Symbols by Name

If you know the name of the character you need:

  1. Enter the term in the Search for: field at the bottom of the Character Map window (e.g., type "degree", "copyright", or "integral").
  2. Click the Search button. The grid will immediately display matching Unicode symbols.

Copying the Symbol to Your Clipboard

  1. Click on the desired character to enlarge it and confirm your selection.
  2. Click the Select button to place the character into the "Characters to copy" text box. You can select multiple characters in sequence if needed.
  3. Click the Copy button.
  4. Open your target application or document and press Ctrl + V to paste the symbol.
