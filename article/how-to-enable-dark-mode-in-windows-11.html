How to Enable Dark Mode in Windows 11

Windows 11 includes a built-in Dark Mode that transforms the appearance of the user interface, including the taskbar, Start menu, File Explorer, and supported applications. Switching to Dark Mode can reduce eye fatigue in low-light environments and improve battery efficiency on devices with OLED displays. This guide outlines the straightforward steps required to activate Dark Mode across your entire Windows 11 operating system and individual applications.

Step 1: Open the Settings Menu

  1. Press the Windows Key + I on your keyboard to open the Settings app.
  2. Alternatively, right-click the Start button and select Settings, or right-click any empty space on your desktop and choose Personalize.

Step 2: Navigate to Color Settings

  1. In the left sidebar of the Settings window, click on Personalization.
  2. On the right-hand panel, scroll down and select Colors.

Step 3: Switch to Dark Mode

  1. Locate the Choose your mode setting near the top of the Colors page.
  2. Click the dropdown menu next to it. You will see three options:
    • Light: Sets standard bright colors across the system and apps.
    • Dark: Instantly applies Dark Mode to the Start menu, taskbar, action center, File Explorer, and all supported native and third-party applications.
    • Custom: Allows you to set your default Windows mode (taskbar, Start menu) and default app mode separately.

To apply Dark Mode across the entire operating system and all apps, select Dark.

Step 4: Apply a Pre-Configured Dark Theme (Alternative Method)

You can also switch themes to achieve a complete visual overhaul with matching dark wallpapers and accent colors:

  1. Open Settings (Windows Key + I) and click Personalization.
  2. Click on Themes.
  3. Select one of the pre-installed dark themes, such as Windows (dark), Glow, or Captured Motion.

Enabling Dark Mode in Web Browsers and Third-Party Apps

Once you select Dark in the main Windows 11 settings, most modern applications—such as Google Chrome, Microsoft Edge, Mozilla Firefox, Spotify, and Microsoft Office—will automatically detect the system preference and switch to dark themes.

If a specific third-party app does not update automatically:

  1. Open the application's internal Settings or Preferences menu.
  2. Look for the Appearance, Theme, or Display section.
  3. Manually select Dark or Match System Default.
