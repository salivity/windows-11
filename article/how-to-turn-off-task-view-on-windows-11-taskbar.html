How to Turn Off Task View on Windows 11 Taskbar

Windows 11 includes a default Task View button on the taskbar to help manage open windows and virtual desktops, but it can easily be removed for a cleaner, more minimalist workspace. This guide provides quick, step-by-step instructions to disable the Task View button using your taskbar settings or the main Windows Settings app.

Method 1: Using the Taskbar Shortcut Menu

  1. Right-click on an empty space on the Windows 11 taskbar.
  2. Click on Taskbar settings from the pop-up menu.
  3. In the settings window, expand the Taskbar items section at the top.
  4. Locate the Task view option.
  5. Toggle the switch next to Task view from On to Off.

The Task View icon will immediately disappear from your taskbar.

Method 2: Using the Windows Settings App

  1. Press the keyboard shortcut Windows Key + I to open the Settings menu.
  2. Select Personalization from the left-hand sidebar.
  3. Scroll down and click on Taskbar on the right side of the window.
  4. Under the Taskbar items section, find Task view.
  5. Switch the toggle to Off.

Keyboard Shortcut Alternative

Hiding the Task View icon does not disable the feature itself. You can still access Task View and manage your virtual desktops at any time by pressing Windows Key + Tab on your keyboard.
