How to Add Exclusions in Windows 11 Defender

This guide explains how to add file, folder, file type, and process exclusions to Microsoft Defender Antivirus on Windows 11. Adding exclusions prevents the built-in antivirus from scanning trusted items, which helps prevent false positives and stops Defender from blocking legitimate software or slowing down specific development directories.

Steps to Add an Exclusion in Microsoft Defender

  1. Open Windows Security

    • Click the Start button, type Windows Security, and press Enter.
    • Alternatively, go to Settings > Privacy & security > Windows Security, then click Open Windows Security.

  2. Navigate to Protection Settings

    • Click on Virus & threat protection in the left sidebar or the main dashboard.
    • Under the Virus & threat protection settings section, click Manage settings.

  3. Access the Exclusions Menu

    • Scroll down to the bottom of the page to find the Exclusions section.
    • Click Add or remove exclusions.
    • When prompted by User Account Control (UAC), click Yes to allow administrative access.

  4. Add Your Exclusion

    • Click the + Add an exclusion button.
    • Select the type of exclusion you want to create from the drop-down menu:
      • File: Select a specific individual file.
      • Folder: Select an entire directory (all contents and subfolders will be excluded).
      • File type: Enter a file extension (e.g., .docx or .log) to exclude all files with that extension.
      • Process: Enter the exact process name (e.g., app.exe) to exclude tasks run by that program.
    • Browse to the file/folder or enter the required name/extension, then confirm your choice.

How to Remove an Exclusion

  1. Return to the Add or remove exclusions page using the steps above.
  2. Locate the item you wish to remove from the list.
  3. Click the drop-down arrow next to the item and click Remove.
