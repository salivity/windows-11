Customize Windows 11 System Tray and Overflow Menu

Windows 11 allows users to tailor the taskbar's system tray and hidden icon overflow menu to maintain a clean and efficient workspace. This guide explains how to manage which application icons remain visible on the taskbar, hide background apps inside the overflow menu using drag-and-drop actions, and configure system-level indicators through the Windows 11 Settings app.

Rearrange and Hide Icons Using Drag and Drop

The fastest way to manage icons in the system tray is directly on the taskbar:

  1. Click the up arrow (^) icon on the right side of the taskbar to open the overflow menu.
  2. Click and hold any app icon inside the overflow menu, then drag it down onto the taskbar to keep it permanently visible.
  3. To hide an icon, click and hold it on the taskbar, then drag it up into the overflow flyout.
  4. You can also reorder icons within the overflow menu by dragging them to your preferred position.

Manage System Tray Icons in Windows Settings

For detailed control over background application icons:

  1. Right-click an empty area of the taskbar and select Taskbar settings (or press Windows Key + I, navigate to Personalization, and select Taskbar).
  2. Click on Other system tray icons to expand the list of installed applications with background processes.
  3. Toggle the switch to On for any application you want permanently displayed in the taskbar corner.
  4. Toggle the switch to Off to move the application icon inside the hidden overflow menu.

Toggle Default System Icons

Windows 11 includes several built-in system indicators that can be toggled on or off:

  1. Open Settings > Personalization > Taskbar.
  2. Expand the System tray icons section near the top.
  3. Toggle the switches on or off for available features such as the Pen menu, Touch keyboard, and Virtual touchpad.

Customize the System Tray Clock and Badges

To further streamline the system tray area:

  1. In the Taskbar settings menu, scroll down and click Taskbar behaviors.
  2. Check or uncheck Show badges on taskbar apps to toggle unread message counters on app icons.
  3. Check or uncheck Show seconds in system tray clock (if supported by your Windows 11 build) to change time precision.
  4. Check or uncheck Select the far corner of the taskbar to show the desktop to enable or disable the quick desktop peek button at the extreme right edge of the screen.
