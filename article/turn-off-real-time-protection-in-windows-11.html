Turn Off Real-Time Protection in Windows 11

Microsoft Defender runs real-time protection in the background to safeguard Windows 11 against viruses, spyware, and other malicious threats. However, certain tasks—such as installing specific trusted software, running developer tools, or troubleshooting false positives—may require this security feature to be suspended. This guide provides a straightforward, step-by-step walkthrough to temporarily disable Microsoft Defender's real-time protection using the Windows 11 Settings interface.

Steps to Temporarily Disable Real-Time Protection

  1. Open Windows Security Click the Start button, type Windows Security in the search bar, and select the top result. Alternatively, double-click the shield icon located in the taskbar system tray.

  2. Access Virus & Threat Protection From the main Windows Security dashboard, click on Virus & threat protection in the left-hand navigation pane or the main panel.

  3. Open Virus & Threat Protection Settings Scroll down to the Virus & threat protection settings section and click the blue Manage settings link.

  4. Toggle Real-Time Protection Off Locate the Real-time protection switch at the top of the page. Click the toggle switch to set it to Off.

  5. Confirm the Action A User Account Control (UAC) prompt will appear asking for permission to make changes to your device. Click Yes to confirm.

Important Notes

  • Automatic Reactivation: Real-time protection will not remain off permanently. Windows 11 is designed to automatically turn this feature back on after a short period, during scheduled maintenance, or when the computer is restarted.
  • Manual Reactivation: To turn real-time protection back on immediately after completing your task, return to the same settings menu and switch the Real-time protection toggle back to On.
