How to Record Steps for Bug Reports in Windows 11

Recording the exact steps to reproduce a software bug provides developers and IT support with the precise context needed to resolve issues quickly. While the classic Steps Recorder (PSR) tool has long been a staple in Windows, Microsoft is phasing it out in favor of modern built-in utilities in Windows 11. This guide covers how to access and use the legacy Steps Recorder while it remains available, as well as how to utilize modern alternatives like the Snipping Tool video recorder, Xbox Game Bar, and the Feedback Hub to generate comprehensive bug reports.

Using the Classic Steps Recorder (PSR)

The Steps Recorder automatically captures screenshots of every click, documents keystrokes, and generates an annotated HTML document inside a ZIP file.

  1. Press Windows Key + R to open the Run dialog.
  2. Type psr and press Enter.
  3. In the Steps Recorder window, click Start Record.
  4. Perform the exact actions that trigger the bug. You can click Add Comment at any point to highlight a specific area of the screen and add custom notes.
  5. Click Stop Record once you finish the demonstration.
  6. Review the captured steps, click Save, and choose a file destination to export the ZIP archive.

Alternative 1: Snipping Tool Screen Recording

The updated Snipping Tool in Windows 11 includes a dedicated video recording feature that captures smooth, lightweight MP4 video clips of your screen.

  1. Open the Snipping Tool from the Start Menu, or press Windows Key + Shift + S.
  2. Select the Video (Camcorder) icon at the top of the toolbar.
  3. Click New, then click and drag a rectangular box over the area of the screen you want to capture.
  4. Click Start to begin the countdown and record the bug.
  5. Click the red Stop button when finished.
  6. Click the Save icon (diskette) to export the recording as an MP4 file to attach to your bug ticket.

Alternative 2: Xbox Game Bar

Xbox Game Bar allows you to record the active window continuously, which is useful when capturing graphical glitches or complex workflows.

  1. Click on the application window where the bug occurs.
  2. Press Windows Key + Alt + R to immediately begin recording.
  3. Reproduce the bug.
  4. Press Windows Key + Alt + R again to stop recording.
  5. Access your saved video in the Videos\Captures folder.

Alternative 3: Windows Feedback Hub (Recreate Problem)

If you are reporting a Windows-specific bug directly to Microsoft or need deep diagnostic telemetry alongside your visual recordings, use the Feedback Hub.

  1. Press Windows Key + F to launch the Feedback Hub.
  2. Select Report a problem and fill in the issue details.
  3. Scroll down to the Attachments section and locate Recreate my problem.
  4. Check Include data about to specify the category, then click Start capture.
  5. Reproduce the issue, click Stop capture, and submit your report with the attached telemetry and screen captures.
