Manage Chrome and Edge PWAs on Windows 11

Progressive Web Apps (PWAs) allow websites to function like standard desktop applications on Windows 11. This guide covers how to locate, configure permissions for, manage startup behavior, and uninstall web applications installed through both Google Chrome and Microsoft Edge, using in-browser controls and native Windows 11 settings.

Managing PWAs in Microsoft Edge

Microsoft Edge offers dedicated controls for viewing and modifying installed web apps.

Accessing Installed Apps

  1. Open Microsoft Edge.
  2. In the address bar, type edge://apps and press Enter (or click the three-dot menu icon in the top-right corner and select Apps > Manage apps).

Configuring App Behavior and Permissions

  • Pinning and Shortcuts: Hover over any app on the edge://apps page, click Details, or right-click the app to pin it to the Windows Taskbar, Start Menu, or desktop.
  • Auto-Start on Device Login: Click Details on the app's card, then toggle the Auto-start on device login option.
  • App Permissions: From the Details page, select Permissions to control camera, microphone, notification, and location access specifically for that web app.
  • Uninstalling: Click the three dots on the app card or open the app window, click the three dots in the title bar, and select Uninstall [App Name]. You can also check the box to clear data from the related domain.

Managing PWAs in Google Chrome

Google Chrome provides similar tools to organize and configure installed web applications.

Accessing Installed Apps

  1. Open Google Chrome.
  2. In the address bar, type chrome://apps and press Enter.

Configuring App Settings

  • Open on Startup: Right-click the app icon on the chrome://apps page and toggle Start app when you sign in.
  • Window Settings: Right-click the app icon to toggle between opening the app in a dedicated window or as a regular browser tab.
  • App Settings & Permissions: Open the PWA, click the three-dot menu in the title bar, and select App info > Settings. From here, adjust permissions such as notifications, cookies, and hardware access.
  • Uninstalling: Right-click the app on chrome://apps and select Remove from Chrome, or open the app, click the three-dot menu in the title bar, and select Uninstall [App Name].

Managing PWAs via Windows 11 Settings

Because Windows 11 registers PWAs as standard desktop applications, you can manage them directly through the operating system without opening a browser first.

Uninstalling via Windows Settings

  1. Open Settings on Windows 11 (press Windows Key + I).
  2. Navigate to Apps > Installed apps.
  3. Scroll through the list or use the search bar to locate the web app by name.
  4. Click the three dots (...) next to the app and select Uninstall.

Managing Startup Behavior via Windows Settings

  1. Open Settings and go to Apps > Startup.
  2. Locate the installed Chrome or Edge web app in the list.
  3. Toggle the switch to On or Off to control whether the application launches automatically when you sign in to Windows.
