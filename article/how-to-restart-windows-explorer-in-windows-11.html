How to Restart Windows Explorer in Windows 11

Restarting Windows Explorer is a quick and effective troubleshooting step when your taskbar, Start menu, or desktop becomes unresponsive in Windows 11. Instead of rebooting your entire computer, you can refresh the graphical user interface by restarting the explorer.exe process. This guide provides a straightforward, step-by-step walkthrough on how to safely restart the Windows Explorer process using the Windows 11 Task Manager.

Step 1: Open Task Manager

You can open Task Manager in Windows 11 using any of the following methods:

  • Press Ctrl + Shift + Esc on your keyboard (the fastest shortcut).
  • Right-click the Start button (Windows icon) on the taskbar and select Task Manager.
  • Press Ctrl + Alt + Delete and choose Task Manager.

Step 2: Locate the Windows Explorer Process

  1. In the Task Manager window, make sure you are on the Processes tab (the icon showing three stacked rectangles on the left sidebar).
  2. If Task Manager is in a compact view, click More details at the bottom to expand it.
  3. Look for Windows Explorer under the Apps section or scroll down to the Windows processes section.

Step 3: Restart the Process

Once you find Windows Explorer, you can restart it using one of two ways:

  • Option A: Click on Windows Explorer to highlight it, then click the Restart task button in the top-right corner of the Task Manager window.
  • Option B: Right-click on Windows Explorer and select Restart from the context menu.

Your screen, desktop icons, and taskbar will briefly flicker or disappear for a second or two. This is normal. Once the process restarts, the graphical interface will reload completely.

What to Do if the Taskbar Doesn't Reappear

If Windows Explorer closes but fails to restart automatically, leaving you with a blank screen:

  1. In Task Manager, click Run new task from the top command bar.
  2. In the "Create new task" dialog, type explorer.exe.
  3. Click OK or press Enter to manually start the Windows Explorer interface.
