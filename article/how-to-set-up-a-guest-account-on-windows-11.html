How to Set Up a Guest Account on Windows 11

Setting up guest access on a shared Windows 11 computer allows temporary visitors to browse the web and run basic applications without gaining access to your private files, installed software settings, or system configurations. While Windows 11 no longer includes the legacy one-click "Guest" account toggle, you can quickly create a secure, restricted local account using either the Command Prompt or the Windows Settings menu.

Method 1: Create a Guest Account Using Command Prompt

Because Windows reserves the exact term "Guest" for system processes, you must use an alternative name like "Visitor" or "Friend."

  1. Click the Start button, type cmd, right-click Command Prompt, and select Run as administrator.
  2. Type the following command and press Enter to create a new user account: 
    net user Visitor /add *
  3. When prompted to set a password, press Enter twice to leave the account password-free.
  4. (Optional) Prevent the account from modifying system files by removing it from administrative groups and ensuring it is only in the basic Users group with this command: 
    net localgroup Users Visitor /add
  5. Close the Command Prompt. The new "Visitor" account will now appear on your Windows 11 login screen.

Method 2: Create a Local Guest Account via Windows Settings

If you prefer using the graphical interface, you can set up a restricted local account through Settings.

  1. Open Settings by pressing Windows Key + I.
  2. Navigate to Accounts in the left sidebar and select Other users.
  3. Click the Add account button next to Add other user.
  4. In the Microsoft account pop-up, click I don't have this person's sign-in information.
  5. Select Add a user without a Microsoft account.
  6. Enter a name for the account (such as GuestUser or Visitor).
  7. Leave the password fields blank if you want guests to log in without a password, or enter a simple temporary password.
  8. Click Next to finalize the setup.

Managing and Removing Guest Access

To keep your shared computer secure:

  • Verify Account Type: Ensure the account remains listed as a Standard User rather than an Administrator under Settings > Accounts > Other users.
  • Remove the Account: When you no longer need the guest profile, go to Settings > Accounts > Other users, click on the account name, and select Remove to delete the account and its temporary data.
