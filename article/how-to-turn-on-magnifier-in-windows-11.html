How to Turn On Magnifier in Windows 11

The Windows 11 Magnifier tool is a built-in accessibility feature that enlarges part or all of your screen to improve visibility. This guide provides the fastest ways to activate and control the Magnifier using keyboard shortcuts, the Windows Settings menu, the Start search bar, and the Windows sign-in screen.

Method 1: Use Keyboard Shortcuts (Fastest)

  • Turn On: Press the Windows logo key + Plus sign (+) on your keyboard.
  • Zoom In: Press the Windows logo key + Plus sign (+) again.
  • Zoom Out: Press the Windows logo key + Minus sign (-).
  • Turn Off: Press the Windows logo key + Esc.

Method 2: Use Windows 11 Settings

  1. Press Windows key + I to open the Settings app.
  2. Select Accessibility from the left-hand navigation pane.
  3. Click on Magnifier under the Vision section.
  4. Toggle the switch next to Magnifier to On.

From this menu, you can also adjust the default zoom level, set zoom increments, and choose whether Magnifier starts automatically after you sign in.

Method 3: Use the Start Search

  1. Press the Windows key or click the Start button.
  2. Type Magnifier into the search bar.
  3. Select the Magnifier app from the search results to launch it immediately.

Method 4: Activate from the Sign-in Screen

  1. On the Windows 11 lock or sign-in screen, locate the Accessibility icon in the bottom-right corner.
  2. Click the icon to open the accessibility menu.
  3. Toggle the Magnifier switch to On.

Useful Magnifier View Modes

Once active, you can switch between different viewing modes using these shortcuts:

  • Full Screen View (Ctrl + Alt + F): Magnifies the entire screen.
  • Lens View (Ctrl + Alt + L): Magnifies the area around your mouse pointer like a magnifying glass.
  • Docked View (Ctrl + Alt + D): Displays a magnified area in a fixed pane at the edge of your screen while keeping the rest normal size.
