Windows 11 Xbox Game Bar Performance Widget Guide

This guide covers everything you need to know about the Xbox Game Bar in Windows 11, focusing specifically on its real-time performance monitoring features. You will learn what this built-in gaming overlay is, how to launch it, and the exact steps required to access, customize, and pin its performance widgets to monitor hardware stats like FPS, CPU, GPU, and RAM usage during gameplay.

What Is the Xbox Game Bar in Windows 11?

The Xbox Game Bar is a native, customizable gaming overlay built directly into Windows 11. It works seamlessly with nearly all PC games, giving players instant access to system controls without having to minimize or leave their game. In addition to performance tracking, the Game Bar includes widgets for screen recording, taking screenshots, adjusting individual audio channels, chatting with friends across Xbox networks, and managing Spotify playback.

How to Access the Performance Widget

To open the Xbox Game Bar and display your system metrics, follow these steps:

  1. Open the Game Bar: Press the Windows Key + G on your keyboard, or press the Xbox button on a connected Xbox controller.
  2. Locate the Widget Menu: If the Performance window does not appear automatically, click the Widget Menu icon (represented by an icon with multiple horizontal lines and boxes) located on the main top bar.
  3. Select Performance: Click on Performance from the drop-down list, or click the monitor icon on the top navigation bar.

Key Features of the Performance Widget

The Performance widget tracks crucial real-time hardware telemetry, including:

  • FPS (Frames Per Second): Monitors frame rates during active gameplay (requires a one-time setup and PC restart for initial permission access).
  • CPU Usage: Tracks central processor utilization percentages.
  • GPU Usage: Shows graphics processor load and clock speeds.
  • VRAM: Displays video memory consumption.
  • RAM: Tracks overall system memory utilization.

How to Pin and Customize the Widget

To view performance metrics continuously while playing without keeping the full Game Bar open:

  1. Pin the Widget: Click the Pin icon in the top-right corner of the Performance widget. This keeps the overlay visible on your screen during active gameplay.
  2. Collapse for Compact View: Click the arrow icon next to the pin to switch to a compact layout that takes up minimal screen space.
  3. Adjust Settings: Click the Performance Options icon (sliders) inside the widget to change the background transparency, theme color, and select which specific metrics (CPU, GPU, RAM, VRAM, FPS) you want displayed.
