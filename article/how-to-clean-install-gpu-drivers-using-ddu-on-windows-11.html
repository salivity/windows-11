How to Clean Install GPU Drivers Using DDU on Windows 11

Performing a clean installation of your graphics card drivers using Display Driver Uninstaller (DDU) removes corrupted files, legacy registry entries, and conflicting driver profiles that standard uninstallers leave behind. This guide provides a straightforward, step-by-step walkthrough for preparing your Windows 11 system, running DDU in Safe Mode, and installing the latest GPU drivers to ensure maximum system stability and performance.

Step 1: Pre-Download Necessary Files

Before removing any software, download all the tools you will need:

  1. Latest GPU Driver: Visit the official website of your graphics card manufacturer (NVIDIA, AMD, or Intel) and download the latest driver package for your specific GPU model.
  2. Display Driver Uninstaller (DDU): Download the latest version of DDU from the official Wagnardsoft website and extract the archive to a convenient location, such as your Desktop.

Step 2: Disconnect from the Internet

Disconnect your PC from the internet by unplugging your Ethernet cable or disabling Wi-Fi. This crucial step prevents Windows 11 from automatically downloading and installing generic display drivers via Windows Update immediately after the cleanup process.

Step 3: Boot Windows 11 into Safe Mode

Running DDU in Safe Mode ensures that no active GPU processes or background services lock driver files during deletion.

  1. Press Windows Key + I to open Settings.
  2. Navigate to System > Recovery.
  3. Next to Advanced startup, click Restart now.
  4. When the blue recovery environment appears, select Troubleshoot > Advanced options > Startup Settings > Restart.
  5. After your PC restarts, press 4 or F4 to enter Safe Mode.

Step 4: Run Display Driver Uninstaller (DDU)

  1. Open the extracted DDU folder and launch Display Driver Uninstaller.exe.
  2. On the right side of the interface, set the Device type dropdown menu to GPU.
  3. Set the Device dropdown menu to your manufacturer (NVIDIA, AMD, or Intel).
  4. Click the Clean and restart button in the top-left corner.
  5. DDU will completely remove all driver components, cache files, and registry entries. Once finished, your computer will automatically restart into normal Windows mode.

Step 5: Install the New Graphics Driver

  1. Once Windows 11 boots normally, locate the graphics driver installer you downloaded in Step 1.
  2. Run the installer as an administrator and follow the on-screen prompts. If given the option, choose a Custom (Advanced) installation and check the box for a Perform a clean installation.
  3. Complete the installation wizard and restart your PC if prompted.

Step 6: Reconnect to the Internet

After the new driver is installed and working correctly, reconnect your Ethernet cable or enable Wi-Fi to restore your internet connection. Your GPU is now fully updated with a clean driver configuration.
