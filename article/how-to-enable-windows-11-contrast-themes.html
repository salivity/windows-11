How to Enable Windows 11 Contrast Themes

Windows 11 includes built-in contrast themes designed to assist users with visual impairments, low vision, or light sensitivity by increasing the color distinctiveness of text and user interface elements. This guide provides step-by-step instructions on how to activate, customize, and quickly toggle these high-contrast themes using Windows 11 settings and keyboard shortcuts.

Enabling Contrast Themes via Settings

  1. Open the Start Menu and select Settings (or press Windows Key + I).
  2. Click on Accessibility in the left sidebar.
  3. In the right pane, select Contrast themes under the Vision section.
  4. Click the dropdown menu next to Contrast themes and choose one of the four pre-configured options:
    • Aquatic (light blue and dark background)
    • Desert (warm tones on a light background)
    • Dusk (purple and muted tones on a dark background)
    • Night sky (high-contrast yellow/blue on a deep black background)
  5. Click Apply to activate the selected theme.

Customizing a Contrast Theme

If the default presets do not fit your specific vision needs, you can customize the individual colors:

  1. In the Contrast themes menu, select the theme you want to modify from the dropdown.
  2. Click the Edit button next to the dropdown menu.
  3. Click on the color box for any element you want to adjust:
    • Background
    • Text
    • Hyperlinks
    • Inactive text
    • Selected text
    • Button text
  4. Use the color palette to choose a new shade and click Done.
  5. Click Save as, enter a custom name for your theme, and select Save and apply.

Quick Toggle with Keyboard Shortcuts

You can turn your chosen contrast theme on or off instantly from any screen:

  • Press Left Alt + Left Shift + Print Screen.
  • A prompt will appear asking if you want to turn on the contrast theme. Select Yes (or press Enter).
  • Press the same shortcut again at any time to return to your standard Windows display settings.
