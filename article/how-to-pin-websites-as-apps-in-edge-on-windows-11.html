How to Pin Websites as Apps in Edge on Windows 11

Microsoft Edge in Windows 11 allows you to install any website as an independent desktop application that runs in its own dedicated window without standard browser toolbars or tabs. This guide provides a straightforward, step-by-step walkthrough for turning web pages into standalone desktop apps, pinning them to your taskbar or Start menu, and managing them within Windows 11.

Step 1: Open the Target Website in Microsoft Edge

Launch Microsoft Edge on your Windows 11 PC and navigate to the website or web application you want to use as a standalone program.

Step 2: Access the Apps Menu

Click the Settings and more menu (represented by the three horizontal dots ...) located in the upper-right corner of the Edge window. Hover your cursor over the Apps option in the drop-down menu.

Step 3: Install the Website as an App

Depending on the website, select one of the following options:

  • Install this site as an app: This appears for standard websites.
  • Install [Site Name]: This appears if the website is built as a Progressive Web App (PWA).

Step 4: Name and Confirm the App

A pop-up dialog will appear asking you to confirm the installation:

  1. Edit the name of the app if you want a custom label.
  2. Click the Install button to convert the site into an independent window.

Step 5: Pin the App in Windows 11

Once installed, the website will immediately launch in its own standalone window, and an "App installed" prompt will appear with shortcut options. Check the boxes based on your preference:

  • Pin to taskbar: Adds a dedicated launch icon directly to your Windows 11 taskbar.
  • Pin to Start: Places the app tile in your Windows 11 Start menu.
  • Create Desktop shortcut: Adds an icon to your desktop screen.
  • Auto-start on device login: Automatically opens the web app when you sign into Windows.

Click Allow to apply your selected pinning preferences.

Managing and Uninstalling Web Apps

To manage or remove an installed site later:

  1. Open Microsoft Edge and navigate to edge://apps in the address bar, or open the Edge menu (...) and click Apps > Manage apps.
  2. Click the three dots next to the installed app to open settings, pin/unpin shortcuts, or select Uninstall to completely remove the app from Windows 11.
