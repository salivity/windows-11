Set Up a Scanner in Windows Fax and Scan Windows 11

Configuring Windows Fax and Scan to work with a physical scanner on Windows 11 requires properly connecting your hardware, installing the necessary drivers, and adding the device inside the application. This guide provides a straightforward, step-by-step walkthrough to help you connect a USB or network scanner, verify its detection in Windows 11, and start scanning documents through Windows Fax and Scan.

Step 1: Connect and Install the Scanner Drivers

Before configuring the software, ensure Windows 11 recognizes your scanner hardware.

  1. Connect the Hardware:
    • For USB scanners, connect the cable directly to your PC and power the scanner on.
    • For Network/Wi-Fi scanners, ensure the scanner is powered on and connected to the same local network as your PC.
  2. Install Drivers:
    • Go to Start > Settings > Bluetooth & devices > Printers & scanners.
    • Click Add device. Windows 11 will scan for connected hardware.
    • If your scanner is detected, click Add device to install the default driver.
    • If Windows does not automatically find the driver, download and install the official driver software from the scanner manufacturer's website.

Step 2: Ensure Windows Fax and Scan Is Installed

Windows Fax and Scan is an optional feature in Windows 11 and may need to be enabled.

  1. Open Settings > System > Optional features.
  2. Look for Windows Fax and Scan in the list of installed features.
  3. If it is not listed, click View features (next to Add an optional feature), search for Windows Fax and Scan, check the box, and click Next > Install.

Step 3: Configure the Scanner in Windows Fax and Scan

Once the driver is active and the tool is installed, link the scanner to the application.

  1. Press the Windows Key, type Windows Fax and Scan, and press Enter.
  2. In the bottom-left corner of the window, click the Scan tab.
  3. Click the New Scan button on the top toolbar.
  4. If prompted with the Select Device dialog box:
    • Select your physical scanner from the list.
    • Click OK.
  5. If no scanner appears, click Change... to search for available devices or verify that your scanner is properly powered on and connected.

Step 4: Perform a Test Scan

Confirm the connection by adjusting your scan preferences and running a test.

  1. In the New Scan window, configure the following settings:
    • Profile: Select the document type (e.g., Documents or Photo).
    • Source: Choose between Flatbed or Feeder (if applicable).
    • Color format: Choose Color, Grayscale, or Black and white.
    • File type: Select JPG, PNG, TIF, or BMP.
    • Resolution (DPI): Set the desired scanning resolution (e.g., 300 DPI for text).
  2. Click Preview to ensure the scanner communicates properly and generates a sample.
  3. Click Scan to complete the process. The scanned file will appear in the main window under the Scanned Documents folder.
