How to Pause or Schedule Windows 11 Updates

Windows 11 automatically downloads and installs cumulative updates to keep your system secure, but these updates can sometimes disrupt your workflow or cause unexpected restarts. Fortunately, Windows 11 provides built-in options to pause updates for up to five weeks, schedule restart times, and set active hours to ensure your computer updates only when it is convenient for you.

How to Pause Windows 11 Updates

Pausing updates temporarily stops Windows from downloading and installing both quality and cumulative updates.

  1. Open the Start menu and select Settings (or press Windows Key + I).
  2. Click on Windows Update in the left sidebar.
  3. Under the More options section, locate the Pause updates setting.
  4. Click the dropdown menu next to "Pause for 1 week" and select your preferred duration (from 1 to 5 weeks).

Windows will not install updates until the selected time period expires. To resume updates earlier, return to this menu and click Resume updates.

How to Schedule an Update Restart

If a cumulative update has already downloaded and requires a reboot, you can schedule the restart for a specific time instead of letting Windows restart automatically.

  1. Open Settings and go to Windows Update.
  2. If an update is pending a restart, click Schedule the restart.
  3. Toggle the switch to On.
  4. Select a specific time and day (up to seven days in advance) for the computer to reboot and finish the installation.

How to Set Active Hours

Setting active hours prevents Windows from automatically restarting your PC while you are actively using it.

  1. Open Settings > Windows Update.
  2. Click on Advanced options.
  3. Select Active hours.
  4. Set the Adjust active hours dropdown to Manually.
  5. Set your Start time and End time (up to an 18-hour window).

Windows will avoid automated reboots during these hours, allowing cumulative updates to install in the background when your PC is idle.

How to Configure Update Schedules via Group Policy (Windows 11 Pro & Enterprise)

For advanced control over when updates are downloaded and installed, use the Local Group Policy Editor:

  1. Press Windows Key + R, type gpedit.msc, and press Enter.
  2. Navigate to: Computer Configuration > Administrative Templates > Windows Components > Windows Update > Manage end user experience.
  3. Double-click Configure Automatic Updates.
  4. Select Enabled.
  5. Under Options, choose option 4 - Auto download and schedule the install, then set your desired day and time for installations.
  6. Click Apply and then OK.
