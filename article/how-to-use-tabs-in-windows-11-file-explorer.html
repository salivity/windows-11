How to Use Tabs in Windows 11 File Explorer

Windows 11 integrates browser-style tabs into File Explorer, fundamentally modernizing how users browse and manage files on their systems. Instead of opening multiple separate windows to view different folders, users can consolidate their file navigation into a single interface with multiple open directories, functioning almost identically to web browsers like Microsoft Edge or Google Chrome.

Opening and Creating Tabs

File Explorer offers several straightforward methods to open new tabs:

  • The Plus Button: A dedicated plus icon (+) sits on the title bar next to existing tabs. Clicking this opens a new tab directed to your default Home or This PC view.
  • Keyboard Shortcuts: Pressing Ctrl + T instantly opens a new tab.
  • Middle-Click Navigation: Clicking a folder with the mouse scroll wheel (middle-click) automatically opens that folder in a new background tab.
  • Context Menu: Right-clicking any folder and selecting "Open in new tab" allows you to keep your current view while launching the target directory alongside it.

Organizing and Moving Between Tabs

Tabs can be managed directly on the tab strip to fit your workflow:

  • Switching Views: You can switch between active directories by clicking on the respective tab or using the keyboard shortcut Ctrl + Tab to cycle forward and Ctrl + Shift + Tab to cycle backward. You can also jump directly to tabs using Ctrl + 1 through Ctrl + 9.
  • Reordering: Tabs can be clicked and dragged horizontally across the top bar to reorder them based on priority.
  • File Transfers Between Tabs: Moving files across different locations is streamlined. You can click and drag a file or folder over another tab's header, wait a moment for that tab to become active, and drop the item into the destination directory.

Closing Tabs

Managing open tabs follows familiar web browser behaviors:

  • Close Button: Click the X icon on the right side of the active tab.
  • Shortcut: Press Ctrl + W to quickly close the current tab.
  • Middle-Click Closure: Middle-clicking on any tab header will immediately close it without needing to select the tab first.

Key Benefits

By adopting browser-style tabs, File Explorer reduces taskbar clutter, simplifies file transfers across deep directory paths, and lowers system memory usage compared to running numerous independent File Explorer instances. The unified sidebar remains static, allowing consistent access to pinned folders, cloud drives, and system drives regardless of which tab is active.
