How to Adjust UAC Settings in Windows 11

User Account Control (UAC) in Windows 11 is an essential security feature designed to prevent unauthorized system modifications by software and standard users. This guide explains how to access the User Account Control settings window, adjust the slider to change notification thresholds, and understand the security implications of each of the four available levels.

Steps to Adjust the UAC Slider in Windows 11

  1. Open Search: Press the Windows Key + S or click the Search icon on the taskbar.
  2. Launch UAC Settings: Type UAC or Change User Account Control settings into the search box and select the matching result.
  3. Move the Slider: In the User Account Control Settings dialog, drag the vertical slider to your desired threshold level.
  4. Save Changes: Click the OK button at the bottom of the window.
  5. Confirm the Prompt: If prompted by UAC to confirm the administrative change, click Yes to apply the new setting.

Understanding the Four UAC Notification Levels

Windows 11 provides four distinct threshold levels on the UAC slider:

  • Always notify (Highest Level): You receive a prompt whenever apps attempt to install software or make changes to your PC, as well as when you modify Windows settings. The desktop is dimmed (Secure Desktop mode) to prevent other programs from interacting with the prompt.
  • Notify me only when apps try to make changes to my computer (Default): You are notified only when programs attempt to make system-level changes or install software. You will not receive notifications when you manually change Windows settings. The desktop is dimmed during prompts.
  • Notify me only when apps try to make changes to my computer (do not dim my desktop): This option provides the same notification triggers as the default setting, but it does not dim the screen. It is primarily used if your computer takes a long time to switch to the Secure Desktop.
  • Never notify (Lowest Level / Disabled): You will never receive prompts when applications attempt to install software, modify system files, or when you change Windows settings. This level leaves your computer vulnerable to malicious software and is not recommended.
