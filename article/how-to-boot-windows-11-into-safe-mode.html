How to Boot Windows 11 into Safe Mode

Safe Mode starts Windows 11 in a basic state using a limited set of files and drivers, making it essential for isolating and troubleshooting hardware and driver conflicts. This guide details the most effective methods to boot Windows 11 into Safe Mode, whether your PC can load the desktop or is unable to boot normally.

Method 1: Access Safe Mode via Windows Settings

If your computer boots normally to the desktop, you can use the Settings menu:

  1. Press Windows Key + I to open Settings.
  2. Go to System and select Recovery.
  3. Under the Recovery options section, find Advanced startup and click Restart now.
  4. Confirm by clicking Restart now again.
  5. After your PC restarts, select Troubleshoot on the Choose an option screen.
  6. Navigate to Advanced options > Startup Settings and click Restart.
  7. After the reboot, press 4 or F4 to start in Safe Mode, or press 5 or F5 for Safe Mode with Networking if you require internet access for driver downloads.

Method 2: Access Safe Mode via the Start Menu or Sign-in Screen

If you cannot access the full Settings app:

  1. Click the Start button (or go to the Windows sign-in screen).
  2. Click the Power icon.
  3. Hold down the Shift key on your keyboard and click Restart.
  4. Keep holding the Shift key until the blue Choose an option screen appears.
  5. Go to Troubleshoot > Advanced options > Startup Settings > Restart.
  6. Press 4 (or F4) to enter Safe Mode.

Method 3: Use System Configuration (msconfig)

Use this method if you need Windows to boot into Safe Mode continuously during extensive troubleshooting:

  1. Press Windows Key + R, type msconfig, and press Enter.
  2. Switch to the Boot tab.
  3. Under Boot options, check the box for Safe boot.
  4. Choose Minimal for standard Safe Mode, or Network for internet access.
  5. Click Apply, then OK, and restart your computer.

Note: To return to normal mode later, reopen msconfig, uncheck Safe boot, and restart.

Method 4: Access Safe Mode from a Black or Non-Booting Screen

If Windows 11 fails to boot properly:

  1. Turn on your PC. As soon as Windows starts loading (or the manufacturer logo appears), hold down the physical power button for 10 seconds to force a shutdown.
  2. Repeat this process two more times (turn on, then force off).
  3. On the third restart, Windows will enter the Automatic Repair environment.
  4. Select Advanced options when prompted.
  5. Go to Troubleshoot > Advanced options > Startup Settings > Restart.
  6. Press 4 (or F4) to load Safe Mode.

Troubleshooting Hardware and Driver Conflicts in Safe Mode

Once inside Safe Mode:

  • Uninstall Problematic Drivers: Right-click the Start button, open Device Manager, locate the conflicting device (often marked with a yellow exclamation mark), right-click it, and select Uninstall device.
  • Remove Recently Installed Software: Go to Settings > Apps > Installed apps to uninstall recently added utilities, antivirus programs, or hardware tools.
  • Run System File Checker: Open Command Prompt as Administrator and execute sfc /scannow to detect and repair corrupted system components.
